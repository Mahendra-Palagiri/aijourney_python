## 🎯 Learning Goals
1. Compute a PDP by hand-logic: for each grid value v of feature f, set f=v FOR EVERYONE, average predictions.
2. Read ICE curves and spot when the PDP average hides two opposite subpopulations (the age×sex case).
3. State PDP's failure under correlated features (it queries impossible combinations — same flaw as Day-1 permutation).
4. Assess calibration: bin predicted probabilities, plot observed frequency — read over/under-confidence.
5. Fix calibration with CalibratedClassifierCV (sigmoid vs isotonic; why isotonic needs more data) WITHOUT
   leaking (calibrate on validation folds, never test).

## 🔍 Core Mechanics
- PDP(f=v) = (1/n)Σᵢ model(xᵢ with f←v): a what-if sweep marginalizing over the real population.
- ICE = the same sweep per individual row; PDP = mean of ICE. Crossing ICE lines ⇒ interactions.
- Calibration matters because Week-5/8 chose ROC-AUC (ranking) — a great ranker can still emit garbage
  probabilities (RF's pushed-to-middle, boosting's pushed-to-extremes signatures). If a DECISION uses the
  probability (expected cost), calibration is part of honesty.
- Brier score = MSE on probabilities; decomposes into calibration + refinement.
