# Week B — Day 2: Shapley Values — The Fair-Credit Math
> Pairs with `2.1.shapley-theory.py` · The mechanics day: no SHAP library yet, just the game theory.

## 📚 Topics
Cooperative game theory framing, the Shapley value formula, its fairness axioms, why exact computation
is exponential, what "the prediction is shared out among features" really means.

## 🎯 Learning Goals
1. Frame prediction as a game: players = features, payout = f(x) − E[f(x)]; a feature's value = its fair share.
2. Compute an exact Shapley value BY HAND for a 3-feature toy model: average marginal contribution over all
   orderings/coalitions. Write out all 3! = 6 orderings.
3. State the axioms (efficiency: shares sum to payout; symmetry; dummy gets 0; additivity) and why they make
   Shapley THE unique fair allocation.
4. Explain the 2^p coalition blow-up and the role of sampling/approximation.
5. Define "marginal contribution given a coalition" precisely — including the subtlety of what "feature absent"
   means for a model that needs all inputs (background/expected values).

## 🔍 Core Mechanics
- φᵢ = Σ over coalitions S ⊆ F\{i} of [|S|!·(|F|−|S|−1)!/|F|!] · (v(S∪{i}) − v(S)).
  The weight is just "probability this coalition precedes i in a random ordering".
- "Absent feature" implementation: replace with background-sample values and average → this single choice is
  where most SHAP confusion lives; nail it today.
- Efficiency axiom = the waterfall plot you'll draw tomorrow MUST sum from base value to prediction exactly.

## 🛠️ Build in the paired .py
1. Toy model f(x1,x2,x3) with a hard-coded formula (include one interaction term): enumerate all coalitions,
   compute exact φ for one instance; verify Σφ = f(x) − baseline.
2. Sampling approximation: estimate φ via random orderings; plot estimate vs #samples converging to your exact value.
3. Show the interaction term's credit gets SPLIT between the two interacting features — Shapley's honest answer
   to "whose effect is it?".

## ⚠️ Common Mistakes
Confusing "feature absent" with "feature = 0" · expecting Shapley to recover the data-generating process
(it explains THE MODEL, right or wrong) · ignoring the baseline when reading values.
