# Week A — Day 3: Bagging & Random Forests — Averaging Away Variance
> Pairs with `3.1.bagging-random-forests.py`

## 📚 Topics
Bootstrap, bagging, why averaging reduces variance, decorrelation via feature subsampling (the RF trick),
OOB evaluation, RF hyperparameters that matter.

## 🎯 Learning Goals
1. Explain the variance-of-the-mean argument: Var(mean of B estimators) shrinks with B — but only the
   uncorrelated part. Write the formula ρσ² + (1−ρ)σ²/B and interpret both terms.
2. Explain why bagging plain trees isn't enough (trees on bootstraps are still correlated — strong
   features dominate every root) and how max_features=√p decorrelates them.
3. Use out-of-bag (OOB) score and state why it's "free CV" (~37% of rows are out of each bootstrap; prove the 1/e).
4. Rank RF hyperparameters by importance: n_estimators (plateau, never overfits with more), max_features
   (the bias-variance dial), min_samples_leaf, max_depth.
5. Say precisely what RF loses vs a single tree: interpretability of one path; and what it keeps: importances.

## 🔍 Core Mechanics
- **Bootstrap**: sample n rows WITH replacement; P(row excluded) = (1−1/n)ⁿ → 1/e ≈ 0.368.
- **Bagging**: B trees on B bootstraps; classify by majority vote, regress by mean. Each tree is
  deliberately overfit (deep); the ENSEMBLE is tamed. Bias ~unchanged, variance ÷.
- **The correlation ceiling**: averaging correlated estimators can't go below ρσ². Random feature
  subsetting at EACH SPLIT (not per tree) breaks the "same strong feature roots every tree" failure.
- **OOB**: each row is predicted by the ~B/e trees that never saw it → honest score without a holdout.
  Verify OOB ≈ CV score on Titanic.

## 🛠️ Build in the paired .py
1. Implement bagging by hand: 50 deep DecisionTreeClassifiers on bootstraps + majority vote; compare
   single-tree vs bagged CV scores.
2. Empirically verify ~36.8% OOB fraction for several n.
3. Sweep max_features ∈ {1, √p, p/2, p}: plot CV mean ± std — find the decorrelation sweet spot.
4. Plot CV score vs n_estimators (10→500): observe the plateau, confirm "more trees never hurts accuracy, only time".
5. Compare your hand-rolled bagger vs RandomForestClassifier (same depth settings): the residual gap IS the per-split feature subsampling.

## ⚠️ Common Mistakes
- Tuning n_estimators as if it could overfit (it plateaus; tune the OTHERS).
- Using shallow trees in RF "to prevent overfitting" (you've added bias twice; RF wants deep trees).
- Comparing OOB to test score from a different split protocol and panicking over noise.
