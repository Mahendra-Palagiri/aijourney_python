## 🎯 Learning Goals

2. Score a candidate split via weighted impurity decrease and pick the best one manually.

4. State what changes for regression trees (MSE/variance instead of impurity).
5. Explain mechanically why trees are scale-invariant and handle mixed feature types.

## 🔍 Core Mechanics
- **Impurity**: Gini = 1 − Σ pᵢ²; Entropy = −Σ pᵢ log₂ pᵢ. Both max at 50/50, zero when pure.
  Compute both for nodes like [5+, 5−], [9+, 1−], [10+, 0−] — feel the curve.
- **Split scoring**: for split S on feature f at threshold t:
  Gain = impurity(parent) − (n_L/n)·impurity(L) − (n_R/n)·impurity(R). The weighting is the point —
  a pure-but-tiny child can't dominate.
- **The algorithm**: for every feature, for every candidate threshold (midpoints of sorted unique
  values), score the split; take the max; recurse on children; stop on max_depth / min_samples / purity.
- **Regression trees**: impurity → node variance; leaf prediction → node mean. Same machinery.
- **Scale invariance**: splits compare x ≤ t; any monotone transform of x produces the same ordering →
  identical tree. This is why Week-4 scaling lessons don't apply here.
- **Categorical features**: sklearn requires encoding; note one-hot's effect on tree splits
  (one level per split) vs ordinal hacks.

## ⚠️ Common Mistakes
- Forgetting the n_L/n weighting (tiny pure leaves look falsely great).
- Comparing entropy and Gini gains across different parents (only within-parent comparisons matter).
- Believing trees "find interactions automatically" at depth 1 — interactions need depth ≥ 2.
