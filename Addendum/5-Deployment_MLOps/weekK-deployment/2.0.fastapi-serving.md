# Week K — Day 2: FastAPI — Your Model as a Service
> Pairs with `2.1.fastapi-serving.py` · `pip install fastapi uvicorn`

## 📚 Topics
HTTP/REST minimum viable knowledge (methods, status codes, JSON bodies), FastAPI fundamentals (routes,
pydantic request/response models, automatic docs), wiring `predict()` behind POST /predict, app lifecycle
(load model ONCE at startup), error handling, testing the API.

## 🎯 Learning Goals
1. Hold the mental model: an API = a typed function callable over the network; FastAPI + pydantic make the
   types literal (Week J-2/K-1 schemas become the API contract for free, including /docs).
2. Build the service: startup event loads the artifact once (NOT per request — measure the difference);
   POST /predict validates → predicts → returns prediction + probability + model version; GET /health returns
   version/uptime (Day 5's monitoring hook, planted).
3. Handle errors as a citizen: 422 (pydantic, free), 400 with explanation, 500 with logged traceback and a
   clean message (never the stack to the client); request logging with latency per call (Week J-2 logging, serving edition).
4. Test it three ways: TestClient unit tests (Week J-1 suite extends!), curl by hand, and a 20-line load
   smoke (100 sequential + 10 concurrent requests; p50/p95 latency recorded — Day 6's vocabulary, met early).
5. Know what's NOT here yet (auth, rate limiting, HTTPS termination) — name them, defer them consciously.

## 🛠️ Build in the paired .py
1. `app.py` serving the Week-I (or Week-8) artifact; /docs screenshot committed.
2. The startup-vs-per-request loading benchmark (one number that justifies an architecture rule).
3. pytest suite via TestClient: happy path, each error class, model-version presence.
4. The smoke-load script + a latency table (p50/p95/max) in the day's notes.

## ⚠️ Common Mistakes
Loading the model per request · letting raw exceptions reach the client · API schema drifting from the
training features silently (one shared pydantic model, imported by both sides — single source of truth).
