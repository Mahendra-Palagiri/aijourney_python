# Week K — Day 3: Docker — Shipping the Whole Environment
> Pairs with `3.1.docker-containerization.py`

## 📚 Topics
Why containers (the works-on-my-machine funeral), images vs containers, Dockerfile anatomy, layer caching
(why instruction ORDER matters), .dockerignore, running/porting/logging/exec-ing, image size discipline,
docker-compose for app+db.

## 🎯 Learning Goals
1. Get the model: image = frozen filesystem + entrypoint (a much heavier `requirements.txt` that also pins the
   OS and Python itself); container = a running instance. Your reproducibility instinct (cached CSVs, pinned
   reqs, seeds) reaches its logical conclusion.
2. Write the Dockerfile for Day-2's API: slim Python base → copy requirements → pip install → copy code →
   uvicorn CMD — and explain WHY requirements is copied before code (layer-cache: deps rebuild only when
   deps change; the single most useful Docker fact).
3. Drive the lifecycle: build, run with port mapping (-p 8000:8000), logs, exec a shell inside, stop/remove;
   curl the containerized API from outside.
4. Mind the size: check image size, cut it (slim base, no dev deps, .dockerignore — your model file might
   belong OUTSIDE via volume mount: discuss trade-off).
5. Compose app + SQLite-backed feature lookup (Week J-3's db!) as two services — the smallest realistic system diagram.

## 🛠️ Build in the paired .py (artifacts: Dockerfile, .dockerignore, compose.yaml + the build log)
1. Dockerfile + build + the containerized smoke test (Day-2's load script against the container).
2. The layer-cache experiment: touch app code → rebuild (fast); touch requirements → rebuild (slow); timings recorded — the lesson, felt.
3. Image-size before/after table (≥30% reduction is the bar).
4. compose.yaml bringing up api+db; one end-to-end request that hits both.

## ⚠️ Common Mistakes
COPY . . before pip install (cache destroyed every edit) · latest tags everywhere (pin bases like you pin
packages) · secrets baked into images (env vars/secrets mounts — even for toy projects, build the reflex) ·
.dockerignore forgotten (the .venv ships, image triples).
