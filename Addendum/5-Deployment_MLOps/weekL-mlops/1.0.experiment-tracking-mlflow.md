# Week L — Day 1: Experiment Tracking — MLflow Ends the Spreadsheet Era
> Pairs with `1.1.experiment-tracking-mlflow.py` · `pip install mlflow`

## 📚 Topics
Why tracking (Week I's hand-kept experiment log, automated), MLflow concepts (runs, params, metrics,
artifacts, experiments), instrumenting sklearn AND PyTorch loops, the UI, querying runs programmatically,
autolog vs explicit logging.

## 🎯 Learning Goals
1. Feel the problem first: re-read your Week-I experiment log (or its absence for Weeks 5–8) — "which config
   produced 0.864?" should be answerable in seconds, forever. That's the entire pitch.
2. Instrument both worlds: the Week-8 sklearn protocol (log params from config, CV mean/std, the pickled
   pipeline as artifact) and a Week-G PyTorch loop (per-epoch metrics — watch curves live in the UI).
3. Organize properly: experiments = projects; runs = attempts; tags for the pre-registration block (protocol
   hash!); artifacts include the EVALUATION REPORT (your harness output — the run carries its own evidence).
4. Query runs as data: mlflow.search_runs → DataFrame → "best run by metric X under constraint Y" — your
   league tables, now generated FROM the tracker (single source of truth).
5. Set the personal law: no experiment without a run ID from today forward. (Autolog is allowed; understand
   what it logs first by doing it explicitly once.)

## 🛠️ Build in the paired .py
1. Week-8 protocol re-run, fully instrumented; screenshot of the comparison view.
2. PyTorch loop instrumented (one Week-G model, 2 configs) — live curves.
3. `best_run_report()` via search_runs reproducing your league-table format from tracker data alone.
4. The time-travel test: pick any logged run, reconstruct its exact result from artifacts alone (no source-diving). If you can't, you logged too little — fix and repeat.

## ⚠️ Common Mistakes
Logging metrics but not params (unreproducible) or params but not the data hash/version (the silent variable) ·
tracker as write-only diary (query it!) · five "final_v2" experiments (naming discipline).
