# Week J — Day 4: Advanced SQL & the Feature Pipeline
> Pairs with `4.1.sql-advanced-pipelines.py`

## 📚 Topics
Window functions (the data scientist's favorite SQL feature), ranking/lag/rolling in SQL, indexes & EXPLAIN
at survival level, pushing feature engineering into the database, SQL→pandas→model pipelines, when SQL vs
pandas (the practical boundary).

## 🎯 Learning Goals
1. Own window functions: `OVER (PARTITION BY … ORDER BY …)` — running totals, ROW_NUMBER/RANK, LAG/LEAD,
   moving averages. Recognize them as Week-H's shift()/rolling() in SQL clothing (same leakage rules! frame
   `ROWS BETWEEN … PRECEDING AND 1 PRECEDING` = shift-before-roll).
2. Build model features IN SQL: per-group aggregates joined back, lag features, time-windowed counts — the
   pattern of every feature store; know why pushing compute to the db wins at scale (data gravity).
3. Read EXPLAIN QUERY PLAN enough to spot a missing index on a JOIN/WHERE column; add the index; measure the speedup.
4. Wire the full pipeline: SQL feature query → pd.read_sql → sklearn Pipeline → model — with the SQL under a
   leakage test (Day-1/Week-H-4 pattern: features at t use only < t).
5. Draw your own SQL-vs-pandas boundary (filtering/joining/aggregating early: SQL; complex stats/ML-adjacent
   transforms: pandas) and write it down as a working rule.

## 🛠️ Build in the paired .py
1. Window-function drill ladder on a synthetic transactions table (10 queries: ranks, lags, 7-day windows).
2. The leakage-safe customer-features query (CTEs + windows) for a churn-style label; verified row-for-row against a pandas implementation.
3. EXPLAIN before/after an index on a deliberately slow JOIN (timings recorded).
4. End-to-end: SQL features → LGBM (Module-2 muscle) → harness evaluation; the whole thing under one pytest.

## ⚠️ Common Mistakes
Window frames including the current row when building features (leakage, SQL edition — the default frame is
not what you think!) · indexes sprinkled without measuring · feature logic duplicated in SQL AND pandas
drifting apart (single source of truth: pick one).
