# 📦 Module 1 — Consolidation Pack

Revision disguised as authoring. Do this immediately after Week 12 closes, while everything is fresh.
No new theory here — every artifact is **harvested from your own main-repo files** (sources noted in each stub).

## Order of work
1. **Question banks** (`questionbanks/`) — qb-week3 … qb-week12 are fully written. For each week:
   - [ ] Answer the Easy/Medium/Tricky tiers in writing (timebox: 1 sitting per tier)
   - [ ] Implement the 5 coding challenges in the paired `qb-weekN_challenges.py`
   - [ ] Self-grade against the original week's materials; mark questions you missed for re-test
2. **Cheat sheets** (`cheat-sheets/`) — numpy, pandas, sklearn, pytorch. Skeletons with sources; fill each from your own lesson code.
3. **Revision sheets** (`revision-sheets/`) — one page per week, strict format, ≤ 60 lines each.

## Definition of done
- [ ] 10 question banks answered + challenges coded
- [ ] 4 cheat sheets complete enough that you stop re-deriving shapes/formulas
- [ ] 10 revision sheets, each readable in under 3 minutes
- [ ] Module row flipped to ✅ in `Addendum/README.md`

## Why this module exists (from the analysis)
The "my attempt vs reference" loop was the repo's best retention tool and it stopped at week 2 —
precisely before the hardest material. Spaced retrieval on weeks 3–12 is the cheapest, highest-value
work in the whole addendum.
