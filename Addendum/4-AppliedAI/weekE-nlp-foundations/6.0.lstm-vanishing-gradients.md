# Week E — Day 6: Vanishing Gradients & LSTMs — Why Memory Needs Gates
> Pairs with `6.1.lstm-vanishing-gradients.py`

## 📚 Topics
The vanishing/exploding gradient problem MEASURED (not just asserted), why repeated multiplication
kills signal, gradient clipping, the LSTM cell (forget/input/output gates, cell state as highway),
GRU as the budget LSTM, what LSTMs still can't do (→ Week F).

## 🎯 Learning Goals
1. Connect immediately back: qb-week9 Tricky-4 computed sigmoid gradient attenuation per LAYER; BPTT multiplies
   per TIME STEP — a 100-word sentence = a 100-layer network. The early words' gradients ≈ 0. Measure it today.
2. Explain the LSTM's fix mechanically: a separate cell state C_t modified only by ADDITION (gated writes/erases),
   so gradient flows along it without repeated matrix multiplication — "the gradient highway".
3. Walk each gate's job in one line: forget (what to erase), input (what to write), output (what to reveal as h_t).
   All three are sigmoids = soft 0/1 switches — Week 5's function in a new job.
4. Use gradient clipping (clip_grad_norm_) and know which problem it fixes (exploding, NOT vanishing).
5. Honestly state LSTM limits: still sequential (no parallelism → slow training), memory still bottlenecked
   through fixed-size state → the cliffhanger Week F resolves.

## 🛠️ Build in the paired .py
1. THE measurement: train vanilla RNN on a synthetic long-dependency task (recall token seen k steps ago) for
   k ∈ {5, 20, 50}; plot accuracy vs k — watch memory die.
2. Instrument gradients: hook `.grad` norms per time step; log-scale plot of gradient norm vs distance-from-loss —
   the vanishing curve, photographed.
3. Same task, nn.LSTM: accuracy vs k again — the rescue, quantified on one overlay plot.
4. Exploding case: remove clipping on a high learning rate; show loss → NaN; add clip_grad_norm_; stable. Both runs logged.
5. Upgrade Day-5's name classifier to LSTM; compare accuracy + training curves.

## ⚠️ Common Mistakes
"LSTMs solve vanishing gradients" stated without the ADDITIVE-cell-state reason · clipping to fix vanishing
(wrong disease) · forgetting LSTM h_n vs c_n are different returns.
