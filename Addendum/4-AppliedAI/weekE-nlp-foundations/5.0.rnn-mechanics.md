# Week E — Day 5: RNNs — Networks That Read in Order
> Pairs with `5.1.rnn-mechanics.py`

## 📚 Topics
Why feed-forward nets can't do sequences natively, the recurrence h_t = f(W_h·h_{t−1} + W_x·x_t + b),
unrolling through time, backprop through time (BPTT), PyTorch nn.RNN/nn.Embedding, padding & packing,
sequence batching shapes.

## 🎯 Learning Goals
1. Explain the core idea: ONE set of weights applied at every time step, with a hidden state h as "memory so far" —
   weight sharing across TIME, exactly as CNNs share across SPACE (say this sentence out loud; it organizes the module).
2. Hand-trace a tiny RNN for 3 time steps on paper: shapes of x_t, h_t, W_h, W_x at every step.
3. Understand unrolling: the RNN is a deep network whose depth = sequence length; BPTT = ordinary backprop on
   the unrolled graph (chain rule across time — Week 9 Day 5's chain gets LONG).
4. Master the PyTorch shapes: input [batch, seq_len, emb_dim] (batch_first=True), output [batch, seq_len, hidden],
   h_n [layers, batch, hidden] — the [N,C,H,W] table of this module; make one for sequences.
5. Handle variable lengths: padding + the reason masks/packed sequences exist (don't let the model learn from PAD).

## 🛠️ Build in the paired .py
1. RNN cell from scratch in NumPy (one function, the recurrence) — process a toy sequence, print h_t per step.
2. Same cell in PyTorch with nn.RNNCell; match outputs (weights copied); then nn.RNN for the batched version.
3. nn.Embedding: show it's just a trainable lookup table (one-hot @ matrix equivalence — prove on paper + code).
4. Train a character-level name classifier (classic exercise: name → language origin) with Embedding → RNN → Linear:
   full Week-10 loop, padding handled, accuracy reported honestly.
5. The shape table for sequences, committed as a docstring you'll reread all module.

## ⚠️ Common Mistakes
batch_first confusion (THE classic; pick True and never deviate) · using output vs h_n incorrectly for
classification (last VALID step, not last padded step!) · letting the loss average over PAD positions.
