# Week E — Day 2: Bag-of-Words, TF-IDF & Your First Text Classifier
> Pairs with `2.1.bow-tfidf-classification.py`

## 📚 Topics
Count vectors, the document-term matrix, TF-IDF weighting (the why), sparse matrices, n-grams,
text classification with the FULL Week-8 protocol, reading what the model learned.

## 🎯 Learning Goals
1. Build the document-term matrix mentally: rows = documents, columns = vocabulary, cells = counts —
   text turned into the tabular data you've handled since Week 2.
2. Derive TF-IDF's logic: term frequency × log(N/df) — "frequent in THIS doc, rare across docs = informative";
   compute one cell by hand.
3. Understand sparsity: 20k vocab × 10k docs but ~99.9% zeros → scipy sparse matrices; why LogReg/NB handle this
   happily and RF chokes.
4. Run an honest protocol: CountVectorizer/TfidfVectorizer INSIDE the Pipeline (fit on train folds only — the
   vocabulary itself can leak!), CV, tune, holdout. Week 8 discipline, new domain.
5. Interpret: top positive/negative coefficients per class = what the model thinks the topic IS.

## 🛠️ Build in the paired .py
1. CountVectorizer from scratch (use Day-1 tokenizer) on a 5-doc toy corpus; verify against sklearn's.
2. TF-IDF by hand for one (doc, term); match sklearn (mind its smoothing variant — read the docs note).
3. Full pipeline on 20newsgroups (4 categories): Tfidf → LogisticRegression; CV mean ± std; confusion matrix; holdout once.
4. N-gram experiment: unigrams vs uni+bigrams — score change vs feature-count explosion (the trade-off table).
5. Top-15 coefficients per class, printed and annotated by hand; find one suspicious feature (leaked header/footer
   artifact — 20newsgroups is famous for them; `remove=('headers','footers','quotes')` and re-run: the score DROP is the lesson).

## ⚠️ Common Mistakes
Vectorizer fit before split · keeping 20newsgroups metadata (your model learns email addresses, not topics) ·
dense-ifying a sparse matrix (`toarray()` on the full DTM → RAM funeral).
