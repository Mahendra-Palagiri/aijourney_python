## 📚 Topics

compared under one protocol, written up Week-8 style.

## 🎯 Learning Goals
1. Pre-register the protocol (Week-A Day-7 habit): dataset, splits, metric, tuning budget per family, decision rule.
2. Field three representation generations fairly: sparse counts → static dense vectors → learned sequential model.
3. Attribute wins/losses to MECHANICS using the week's experiments (order sensitivity? synonym handling? data hunger?).
4. Produce `weekE_defense.md` including: per-class errors, 5 misclassified examples READ AND EXPLAINED per model,
   cost columns (train time, params, inference latency), and "what each generation cannot see".
5. End with written predictions for Week F: "where will a transformer beat my LSTM, and why?" — test them next week.
