# Week F — Day 2: Multi-Head Attention, Positional Encoding & the Block
> Pairs with `2.1.multihead-positional-architecture.py`

## 📚 Topics
Why multiple heads, head splitting/concat mechanics and shapes, positional encodings (the order problem returns!),
residual connections + LayerNorm, the feed-forward sublayer, assembling THE transformer block.

## 🎯 Learning Goals
1. Explain multi-head as "several attention lookups in parallel, each in a lower-dim subspace, concatenated" —
   different heads CAN specialize (syntax-ish, position-ish, topic-ish; inspect, don't romanticize).
2. Master the shape choreography: [B, T, d] → reshape to [B, h, T, d/h] → attention per head → concat back →
   output projection. This is Week-10/11 shape discipline at its hardest; trace it 3 times.
3. Spot the hole YOU already know about: attention is permutation-equivariant — "dog bites man" problem returns
   (Week E-4 Day's demo)! Positional encodings (sinusoidal or learned) add order back INTO the embeddings.
4. Explain residuals + LayerNorm as trainability plumbing: residual = gradient highway (the LSTM cell-state
   trick, generalized — connect it!), LayerNorm = per-token activation stabilizer.
5. Assemble and parameter-count one block: MHA + FFN(4×expand) + 2 norms + residuals; compute params by hand
   for d=128, h=4; verify vs PyTorch.

## 🛠️ Build in the paired .py
1. MultiHeadAttention module from scratch (using Day-1's core): the reshape gymnastics, asserted shapes at every line.
2. Sinusoidal positional encodings: implement, plot the classic stripe heatmap, then PROVE the point — shuffle input

4. Head-specialization peek: 2-layer model on toy data; heatmap each head on one sentence; caption what each seems to do (honestly: "unclear" is a valid caption).
5. Stack 2 blocks + classifier head → tiny text classifier; train on Week-E data with the Week-10 loop. It should work. Savor that.

## ⚠️ Common Mistakes
Reshape vs permute errors in head splitting (assert shapes EVERYWHERE) · forgetting the output projection W_O ·
post-norm vs pre-norm confusion when comparing references · adding PE after the first block instead of at the input.
