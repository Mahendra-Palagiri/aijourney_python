# Week F — Day 3: Build & Train a Tiny GPT — Language Modeling from Scratch
> Pairs with `3.1.tiny-gpt-training.py` · Karpathy-nanoGPT-style day, sized for a laptop CPU/MPS.

## 📚 Topics
Language modeling as next-token prediction, causal self-attention (Day-1's mask, now load-bearing),
the GPT recipe (embeddings + PE → N blocks → LM head), cross-entropy over vocabulary, sampling strategies
(greedy/temperature/top-k), watching a model learn to spell then to phrase.

## 🎯 Learning Goals
1. Define an LM precisely: model of P(next token | previous tokens) — a categorical distribution per position
   (Week D-1 vocabulary, deployed). EVERY chat model is this objective at scale; today removes all mystique.
2. Build the data pipeline: one long text → overlapping (context, target) windows where targets = inputs shifted
   by one; understand why ONE forward pass trains ALL positions simultaneously (the causal mask makes it honest).
3. Assemble TinyGPT from Day-2 blocks (~150 lines): token emb + pos emb → blocks → LayerNorm → Linear to vocab.
4. Train on tiny-shakespeare (char-level, ~1MB): cross-entropy falling = the model literally learning English
   spelling → words → cadence. Sample at checkpoints and WATCH it.
5. Implement sampling: greedy (repetitive), temperature (entropy dial — Week D-1 again), top-k; explain each
   knob's effect mechanically.

## 🛠️ Build in the paired .py
1. Char-tokenizer + windowed Dataset/DataLoader (Week-10 muscle memory, new data shape).
2. TinyGPT module (d=128, 4 heads, 4 blocks, context 128 — fits CPU); param count printed and hand-verified.
3. Training loop with val split, loss curves, and generated 200-char samples at epochs 0/1/5/end — commit the
   samples in comments; they're the week's best artifact.
4. Sampling functions; the same prompt at temperature 0.2/0.8/1.5 — three outputs, one caption each.
5. Bonus honesty check: bits-per-character vs a unigram baseline (your model must beat frequency-guessing decisively).

## ⚠️ Common Mistakes
Target misalignment (off-by-one in the shift = model learns identity) · forgetting the causal mask (val loss
suspiciously great = it's cheating, it can see the answer) · judging by loss alone (READ the samples).
