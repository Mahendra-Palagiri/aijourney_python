# Week F — Day 1: Attention from Scratch — Queries, Keys, Values
> Pairs with `1.1.attention-math.py` · The most important single day in the Addendum. Go slow.

## 📚 Topics
The bottleneck attention solves (Week E-6's cliffhanger), attention as soft dictionary lookup,
queries/keys/values, scaled dot-product attention, the full formula softmax(QKᵀ/√d_k)V computed BY HAND,
attention weights as interpretable alignments.

## 🎯 Learning Goals
1. Motivate from pain you've FELT: the LSTM squeezes a whole sequence through one fixed vector; attention instead
   lets every position look directly at every other — no distance penalty, no memory bottleneck.
2. Hold the dictionary metaphor: query = "what I'm looking for", key = "what I contain", value = "what I'll give you";
   attention = a SOFT lookup that returns a weighted mix of all values.
3. Compute, by hand, on paper, with 3 tokens and d=4: Q=XW_Q, K=XW_K, V=XW_V → scores QKᵀ → scale by √d_k →
   softmax per row → weighted sum of V. Every matrix written out. (This is THE exercise; budget 90 minutes.)
4. Explain each piece's purpose: dot product = similarity (Week D-4!); √d_k scaling = keep softmax out of
   saturation (variance of dot products grows with d — derive it); softmax = differentiable argmax (Week 9).
5. Recognize self-attention output shape: [seq, d] in → [seq, d] out — a sequence-to-sequence layer with
   no recurrence, hence PARALLELIZABLE (the training-speed revolution, name it explicitly).

## 🛠️ Build in the paired .py
1. The paper exercise verified: NumPy attention (≤15 lines) reproducing your hand computation exactly.
2. Attention-weight heatmap for a toy sentence; verify rows sum to 1; read one row aloud ("token 3 attends 70% to token 1…").
3. The √d_k experiment: distribution of QKᵀ entries with/without scaling at d ∈ {4, 64, 512}; softmax entropy collapse without it.
4. Causal mask: implement the upper-triangular −inf mask; show position t cannot see t+1 (this single line is what
   makes a LANGUAGE MODEL possible — flag it for Day 4).
5. Match torch.nn.functional.scaled_dot_product_attention on the same inputs.

## ⚠️ Common Mistakes
Memorizing the formula without the dictionary story · forgetting WHICH axis softmax runs over (rows: each query's
weights) · skipping the hand computation (everything downstream is hollow without it).
