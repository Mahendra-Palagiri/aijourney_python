# Week F — Day 4: The Pretrained World — Hugging Face, BERT-style vs GPT-style
> Pairs with `4.1.huggingface-pretrained.py` · `pip install transformers datasets`

## 📚 Topics
Pretraining/fine-tuning paradigm, encoder (BERT: masked-LM, bidirectional) vs decoder (GPT: causal) families,
the HF stack (tokenizers, AutoModel, pipelines), contextual embeddings (the Week-E-3 fix), feature
extraction with frozen models.

## 🎯 Learning Goals
1. Frame the paradigm shift: Week E-4 transferred WORD vectors; now we transfer the WHOLE NETWORK — millions of
   GPU-hours of representation learning, downloadable. (Same logic as eigen-faces → conv features → this; the
   module's macro-theme completes.)
2. Distinguish the families by OBJECTIVE: BERT = fill-in-the-blank (sees both sides; great at understanding tasks);
   GPT = next-token (generation). Day 3 built the second; today you can read both architectures fluently.
3. Drive the HF API at two levels: `pipeline()` (demo level) and tokenizer+AutoModel (real level: input_ids,
   attention_mask, hidden states, logits — all shapes you now recognize).
4. SEE contextual embeddings fix polysemy: "bank" in two sentences → different vectors (cosine ~0.6, not 1.0) —
   the Week-E-3 limitation, dissolved. This experiment is the day's centerpiece.
5. Use a frozen model as a feature extractor: [CLS]/mean-pooled hidden states → LogReg — often beats everything
   from Week E at 1% of the effort. Run it under the Week-E protocol and add the row to the table.

## 🛠️ Build in the paired .py
1. Tokenizer autopsy: run BPE/WordPiece on 5 tricky strings (long words, typos, emoji, code); print the subword
   splits; connect to Week E-1's mini-BPE.
2. The polysemy experiment (bank/bank/riverbank cosines, distilbert hidden states) + a UMAP of 50 contextualized
   uses of one ambiguous word, colored by sense (hand-labeled).
3. Frozen-feature classifier on the Week-E dataset; append to the league table (it should embarrass your LSTM; say why in one paragraph: data, params, pretraining corpus).
4. Probe layers: same classifier on hidden states from layers 1/6/12 — plot score vs layer (representation depth, measured).
5. `pipeline()` tour (sentiment, NER, summarization) — 10 minutes of fun, then back to mechanics.

## ⚠️ Common Mistakes
Forgetting the attention_mask with padding (silent garbage for short texts) · mean-pooling over PAD tokens
(mask first!) · treating [CLS] as magic (it's just position 0, trained to be useful — for SOME models).
