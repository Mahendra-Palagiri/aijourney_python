# Week G — Day 3: Transfer Learning — Standing on ImageNet
> Pairs with `3.1.transfer-learning-finetune-resnet.py` · The week's centerpiece; the Week-F Day-4/5 story, visual edition.

## 📚 Topics
What CNN features ARE layer by layer (edges → textures → parts → objects), why early features transfer
universally, ResNet in one diagram (residuals — you know them from Week F-2!), frozen-backbone feature
extraction vs fine-tuning, the decision rules (data size × domain similarity).

## 🎯 Learning Goals
1. Tell the feature-hierarchy story with evidence, not faith: visualize first-layer filters of pretrained
   ResNet (they're Gabor-like edges — compare with your hand-made Week-11 kernels!).
2. Map the options exactly onto Week F-5's dial: frozen backbone + new head ↔ frozen features; unfreeze last
   block ↔ partial; full fine-tune ↔ full. Same logic, same LR warnings (small for pretrained parts, larger for the new head — differential LRs).
3. Read ResNet18's architecture: stem → 4 stages → avgpool → fc; replace fc for your classes; count what's trainable in each regime.
4. Run the three regimes on CIFAR-10 under one protocol; compare ALSO against your best from-scratch Day-2 model —
   the gap is the value of a million pretraining images, quantified.
5. State the decision rules: small data + similar domain → freeze; lots of data + different domain → fine-tune
   more; tiny data + very different domain → frozen features + classical model (LogReg on embeddings!).

## ⚠️ Common Mistakes

backbone and head · unfreezing everything on 5k images (forgetting Week F-5's catastrophic-forgetting lesson).
