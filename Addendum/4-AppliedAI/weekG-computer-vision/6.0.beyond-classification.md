# Week G — Day 6: Beyond Classification — The CV Task Landscape
> Pairs with `6.1.beyond-classification.py` · A guided-tour day: breadth deliberately, mechanics-sampled.

## 📚 Topics
Object detection (boxes: the IoU/NMS core ideas), semantic segmentation (per-pixel classification — the
output is an IMAGE), vision transformers (patches as tokens — Weeks F and G shake hands), CLIP-style
image-text embeddings (shared space → zero-shot), choosing the right task framing for a problem.

## 🎯 Learning Goals
1. For each task, nail INPUT → OUTPUT shape and the loss family (detection: boxes+classes, IoU-based matching;
   segmentation: [N, classes, H, W] logits, per-pixel CE — your Week-11 CE, broadcast over pixels).
2. Compute IoU by hand for two boxes; explain NMS in 3 steps (sort by confidence, keep, suppress overlaps).
3. Get the ViT punchline mechanically: image → 16×16 patches → linear projection = "patch embeddings" →
   TRANSFORMER (Week F-2's block, unchanged) → classify. One architecture is eating both fields; you have
   now personally built both halves of the story.
4. Run CLIP zero-shot: embed images and label-texts in the shared space, cosine-classify (Week D-4's function,
   again) — classification WITHOUT training, and why that works (contrastive pretraining, concept level).
5. Practice task framing: for 5 scenario cards (defect detection, crowd counting, doc scanning, etc.) pick
   classification/detection/segmentation + justify — the applied-ML skill interviews actually probe.

## 🛠️ Build in the paired .py
1. IoU + NMS from scratch on toy boxes; visualize before/after suppression.
2. Pretrained detector (torchvision fasterrcnn) on 5 of your own photos; draw boxes; read confidences critically.
3. Pretrained segmentation (deeplabv3) on the same photos; overlay masks; inspect boundary quality.
4. CLIP zero-shot on CIFAR-10 classes (open_clip or HF): accuracy vs your Day-3 fine-tuned ResNet — tabulate
   the trade (zero training vs n epochs).
5. ViT vs ResNet18 feature extraction on 100 images: just shapes and a UMAP comparison — feel the convergence.

## ⚠️ Common Mistakes
Treating detector confidences as calibrated (Week B-4 says check) · judging segmentation by vibes instead of
IoU/Dice · skipping the task-framing exercise (the day's most transferable skill).
