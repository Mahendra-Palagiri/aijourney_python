# Week G — Day 7: CV Mini-Project & Defense
> Pairs with `7.1.cv-miniproject.py`

## 📚 Topics
Consolidation: a small real image problem end-to-end with the full Week-G machinery, defended.

## 🎯 Learning Goals
1. Pick a REAL small dataset (not CIFAR — e.g., a Kaggle/HF image set you care about: plants, food, products;
   2k–20k images, modest classes). Real data = real mess: imbalance, duplicates, label noise. Finding and
   HANDLING that mess is the project.
2. Pre-register: metric (per-class aware if imbalanced — Week 5 lessons), splits (dedupe FIRST — qb-week12
   Tricky-4's near-duplicate trap, now hunted proactively with ImageHash), budget, decision rule.
3. Field three candidates honestly: best from-scratch CNN (Day-2 recipe), frozen features + classical,
   fine-tuned ResNet (Day-3 regimes — you can predict the winner; verify).
4. Apply the Day-4 kit in full: per-class table, confusion grids, Grad-CAM on errors, one slicing study,
   reliability + temperature scaling.
5. Write `weekG_defense.md` + model card (Week B-5 format): data provenance and its biases, intended use, limits.

## 🛠️ Deliverables
- [ ] Dedupe report (how many near-dupes found and removed) · - [ ] Pre-registration block
- [ ] Three-candidate table (CV ± std where feasible, holdout once) · - [ ] Full evaluation kit outputs
- [ ] `weekG_defense.md` + model card · - [ ] Retrospective: scratch-vs-transfer in your own words, 10 lines

## ⚠️ Common Mistakes
Dataset too clean (the mess is the curriculum) · skipping dedupe then celebrating inflated accuracy ·
Grad-CAM only on successes (the errors are where it earns its keep).
