# Week H — Day 3: Classical Forecasting — Baselines, Exponential Smoothing, ARIMA
> Pairs with `3.1.classical-forecasting-arima.py`

## 📚 Topics
Forecasting baselines (naive, seasonal-naive — surprisingly hard to beat: the LogReg-baseline lesson of this
domain), exponential smoothing family (simple → Holt → Holt-Winters), ARIMA(p,d,q) demystified via Day 2's
ACF/PACF, seasonal ARIMA in brief, forecast intervals, honest backtesting.

## 🎯 Learning Goals
1. Implement the baselines FIRST and treat any model that can't beat seasonal-naive as decoration (write this
   sentence in the file header).
2. Build exponential smoothing from scratch: level update ℓ_t = αy_t + (1−α)ℓ_{t−1} — a recursive weighted
   memory (an RNN hidden state with one parameter! say it out loud; Week E-5 smiles); extend conceptually to Holt (trend) and Holt-Winters (seasonality).
3. Decode ARIMA's three letters mechanically: AR(p) = regression on own lags (Week 6 regression, lagged design
   matrix!); I(d) = how many diffs to stationarity (Day 2); MA(q) = regression on past forecast ERRORS; choose
   orders from ACF/PACF signatures + AIC.
4. Produce forecast INTERVALS, not just points (Week D-2's uncertainty discipline) — and verify empirical coverage.
5. Backtest honestly: rolling-origin evaluation (refit, forecast h-ahead, slide) = the only legitimate CV here
   (TimeSeriesSplit's logic, fully realized); metric = MAE/RMSE per horizon h.

## 🛠️ Build in the paired .py

## ⚠️ Common Mistakes
Skipping baselines (the field's #1 embarrassment generator) · evaluating with random-split CV (look-ahead leakage —
instant disqualification) · in-sample fit admired instead of out-of-sample backtest · intervals never coverage-checked.
