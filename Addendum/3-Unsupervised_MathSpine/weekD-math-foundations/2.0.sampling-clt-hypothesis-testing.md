# Week D — Day 2: Sampling, CLT & Hypothesis Testing — Where p-values Come From
> Pairs with `2.1.sampling-clt-hypothesis-testing.py` · The day Week 6's statsmodels output stops being mysterious.

## 📚 Topics
Sampling distributions, standard error, CLT, confidence intervals, hypothesis-test logic, t-tests,
p-values (precise meaning), bootstrap as the simulation-age alternative.

## 🎯 Learning Goals
1. Define the sampling distribution: the distribution of a STATISTIC over hypothetical repeated samples —
   simulate it, don't just read it.
2. State the CLT (means of n iid draws → Normal(μ, σ²/n) regardless of source shape) and watch it happen.
3. Build a 95% CI for a mean and give the correct interpretation (the PROCEDURE captures truth 95% of the time).
4. Run the hypothesis-test ritual: H₀ → test statistic → "how surprising is my data IF H₀?" → p-value.
   Define p-value precisely: P(data this extreme | H₀ true). NOT P(H₀ true | data).
5. Bootstrap anything: resample with replacement → statistic each time → empirical sampling distribution.
   (You met this in qb-week12 challenge 1 — now it has a name and a justification.)

## 🔍 Core Mechanics — connect backwards
- Week 6's coefficient p-values: H₀ is "β=0"; the t-stat is β̂/SE(β̂); now re-read your old statsmodels
  summary line by line — every number should now have a meaning.
- Week 7's "CV folds give a distribution" intuition = sampling-distribution thinking; the fold-std caveat
  (qb-week7 Tricky-2) is a dependence violation you can now articulate.
- Standard error σ/√n: why 4× data → only 2× precision — the cruel square root that shapes all of ML evaluation.

## 🛠️ Build in the paired .py

3. Two-sample t-test from scratch (statistic + p via scipy) on synthetic A/B data; confirm with `scipy.stats.ttest_ind`.
4. Bootstrap CI for a MEDIAN (no formula exists — bootstrap shines) and for the AUC of your Week-8 model.
5. p-hacking demo: test 20 random noise "features" against a target; ~1 comes out p<0.05; connect to qb-week7 Tricky-4.

## ⚠️ Common Mistakes
p-value as P(H₀) · "significant" = "important" (effect size!) · CI interpreted as "95% chance truth is in THIS interval" ·
running tests until something passes (you just demoed why).
