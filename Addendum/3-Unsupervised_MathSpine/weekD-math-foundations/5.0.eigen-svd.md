# Week D — Day 5: Eigenvectors, Eigenvalues & SVD — Special Directions
> Pairs with `5.1.eigen-svd.py`

## 📚 Topics
Eigenvector/eigenvalue meaning, diagonalization, symmetric-matrix niceness, SVD (the general-purpose
decomposition), low-rank approximation, where each shows up in ML.

## 🎯 Learning Goals
1. Define Av = λv geometrically: directions the transformation only STRETCHES (no rotation off-axis);
   λ = the stretch factor. Find them visually first (which grid lines didn't turn?).
2. Know the symmetric-matrix gifts (real eigenvalues, orthogonal eigenvectors) and why covariance matrices —
   being symmetric — always grant them. This is WHY PCA's components are orthogonal.
3. Read SVD A = UΣVᵀ as: rotate (Vᵀ) → scale axes (Σ) → rotate (U); every matrix, even rectangular, factors this way.
4. Use low-rank approximation: keep top-k singular values → best rank-k approximation (Eckart–Young);
   THE compression theorem behind PCA reconstruction and (later) LoRA-style ideas in Module 4-F reading.
5. Map the appearances: PCA (eigen of covariance / SVD of centered X), spectral ideas in graphs, attention-head
   analysis, matrix-factorization recommenders — recognize the same hammer everywhere.

## 🛠️ Build in the paired .py
1. Eigen-hunt visually: transformation-grid plot for a symmetric A; overlay computed eigenvectors (np.linalg.eigh) —
   confirm they're the un-rotated directions, orthogonal.
2. Power iteration from scratch (repeated A@v + normalize) → dominant eigenvector; compare to NumPy. (10 lines;
   demystifies "computing eigenvectors" forever.)
3. SVD image compression: grayscale photo, reconstruct at k=5/20/50; plot quality vs storage — the tactile Eckart–Young.
4. Re-derive Week-C PCA both routes on the same data: eigh(covariance) vs svd(X_centered); show identical components
   and λᵢ = sᵢ²/(n−1) numerically.
5. Verify orthogonality: components @ components.T ≈ I.

## ⚠️ Common Mistakes
Expecting eigenvectors of NON-symmetric matrices to be orthogonal (no) · sign/order confusion when comparing
decompositions · using eig instead of eigh on symmetric matrices (slower, complex-dtype surprises).
