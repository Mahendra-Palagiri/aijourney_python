## 🎯 Learning Goals
1. Derive Bayes' theorem from the definition of conditional probability (two lines) — never memorize it again.
2. Solve the canonical medical-test problem (1% base rate, 95% sensitivity, 10% false positive) by COUNTING
   a population of 10,000 — feel base-rate neglect dissolve.
3. Name the parts: posterior ∝ likelihood × prior; explain each in the medical example.
4. Build Naive Bayes: per-class feature likelihoods + the "naive" conditional-independence assumption;
   know why it still works surprisingly often (decision only needs the argmax, not calibrated probabilities — connect to Week B Day 4!).
5. Frame MLE as "MAP with a flat prior" — one sentence that links Week 5's loss minimization to today.

## 🔍 Core Mechanics
- The counting table (disease × test result) IS Bayes' theorem — every Bayes problem should start as a table
  until intuition is automatic.
- Sequential updating: today's posterior = tomorrow's prior; simulate coin-bias estimation as evidence accumulates
  (Beta prior → Beta posterior, shown numerically — no conjugacy theory needed, just grids).
- Spam filtering = Naive Bayes' historic home: P(spam|words) ∝ P(spam)·ΠP(wordᵢ|spam) — log it to avoid underflow
  (and notice: sums of log-likelihoods = the same shape as every loss you've ever minimized).

## ⚠️ Common Mistakes
P(A|B) ↔ P(B|A) swap (the entire point of today) · priors treated as cheating (they're assumptions made EXPLICIT —
frequentist methods have them too, hidden) · NB probability outputs taken at face value (uncalibrated by construction).
