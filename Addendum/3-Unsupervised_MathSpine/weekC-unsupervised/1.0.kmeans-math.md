# Week C — Day 1: k-Means — Objective, Algorithm, Failure Modes
> Pairs with `1.1.kmeans-math.py` · First week with NO labels — recalibrate what "good" even means.

## 📚 Topics
The unsupervised setting, k-means objective (inertia/WCSS), Lloyd's algorithm, initialization sensitivity,
k-means++ idea, what k-means assumes about cluster shape.

## 🎯 Learning Goals
1. State the objective: minimize Σ‖xᵢ − μ_c(i)‖² and why both steps of Lloyd's algorithm monotonically decrease it.
2. Narrate Lloyd's loop: assign each point to nearest centroid → recompute centroids as means → repeat to convergence.
3. Prove (informally) convergence: finite assignments, objective decreases each step → must stop. But: LOCAL optimum only.
4. Explain why scaling is MANDATORY here (distance-based — same argument as KNN from qb-week3 Tricky-5).
5. List the shape assumptions: spherical, similar size/density clusters; predict the failure on elongated/nested shapes.

## 🔍 Core Mechanics
- Assignment step = Voronoi partition; update step = per-cluster mean minimizes squared distance (calculus you own from Week 6).
- Different random inits → different local optima → run n_init times keep best inertia (sklearn default does this).
- k-means++ seeding: pick next centroid ∝ squared distance from current ones → spread-out start, better optima, provable bound.

## ⚠️ Common Mistakes
