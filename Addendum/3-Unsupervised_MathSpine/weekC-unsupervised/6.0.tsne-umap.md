# Week C — Day 6: t-SNE & UMAP — Nonlinear Maps, Honest Reading
> Pairs with `6.1.tsne-umap.py` · `pip install umap-learn`

## 📚 Topics
Why linear projection isn't enough, t-SNE's neighbor-preserving idea, perplexity, UMAP's speed/structure
trade-offs, the long list of things these plots can NOT tell you.

## 🎯 Learning Goals
1. Explain t-SNE at intuition level: convert distances to neighbor PROBABILITIES in high-D and low-D;
   move low-D points until the two distributions match (KL divergence). Local structure is the contract.
2. Use perplexity correctly: ~"effective #neighbors"; sweep it and watch the map reorganize (5/30/100).
3. Recite the reading rules: cluster SIZES mean nothing; inter-cluster DISTANCES mean little;
   axes mean nothing; run-to-run layouts differ (t-SNE) — only neighborhood membership is trustworthy.
4. Contrast UMAP: faster, somewhat better global structure, has transform() for new points (t-SNE doesn't —
   why that matters for pipelines).
5. Position all three: PCA (linear, fast, invertible, axes meaningful) vs t-SNE/UMAP (nonlinear, for eyes only).

## 🛠️ Build in the paired .py
1. digits dataset: PCA vs t-SNE vs UMAP side by side, colored by true label — the motivating triptych.
2. Perplexity sweep grid (5/30/100) on the same data; caption each with what changed.
3. The cautionary plot: t-SNE on pure Gaussian NOISE — it manufactures visual clusters; never forget this one.
4. Cluster-then-visualize workflow: k-means labels from Day 1 painted onto the UMAP map — agreement check
   between clustering and embedding (they're independent evidence).

## ⚠️ Common Mistakes
Reading t-SNE cluster size/spacing as density/similarity · publishing one cherry-picked random_state ·
running t-SNE on 500 raw dims (PCA to ~50 first — standard recipe).
