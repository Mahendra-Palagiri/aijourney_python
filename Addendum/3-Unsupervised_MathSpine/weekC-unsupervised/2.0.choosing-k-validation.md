# Week C — Day 2: How Many Clusters? Validation Without Labels
> Pairs with `2.1.choosing-k-validation.py`

## 📚 Topics
Elbow method (and its squishiness), silhouette score, cluster stability under resampling,
internal vs external validation, the honest answer ("k is a modeling choice").

## 🎯 Learning Goals
1. Explain why inertia ALWAYS decreases with k (more centroids can only help) → why the elbow is a heuristic, not a test.
2. Compute silhouette s = (b−a)/max(a,b) by hand for one point; interpret s≈1, 0, <0.
3. Use stability as evidence: re-cluster bootstrap samples; stable k = similar partitions (measure with ARI).
4. Distinguish internal metrics (silhouette, inertia) from external (ARI/NMI vs known labels — only for benchmarking).
5. Accept and articulate: with real data, k encodes the QUESTION (how many segments are useful?), not a hidden truth.

## 🔍 Core Mechanics
- Silhouette's a = mean intra-cluster distance, b = mean distance to NEAREST other cluster — a per-point honesty score; the mean-silhouette-vs-k plot usually beats the elbow.
- Adjusted Rand Index: agreement between two partitions corrected for chance — works without label names, perfect for stability checks.
- Stability protocol: for each k: 20 bootstrap re-clusterings → mean pairwise ARI → plot vs k.

## 🛠️ Build in the paired .py
1. Elbow + silhouette curves on blobs with TRUE k=4 (sanity: both should agree here).
2. Same curves on Titanic numeric features (real data, no true k): watch them disagree; write down what you'd report.
3. Implement the stability protocol; overlay stability-vs-k with silhouette-vs-k.
4. Silhouette plot (per-point bars, sklearn example style) for the chosen k: identify the weakest cluster.

## ⚠️ Common Mistakes
Reading the elbow where you want it · comparing silhouette across different DISTANCE SCALES/preprocessing ·
using external metrics in production reports where no labels exist.
