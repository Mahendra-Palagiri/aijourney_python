# Week C — Day 7: Anomaly Detection + Mini-Project

## 📚 Topics
Anomaly types, z-score/IQR recap (Week 4) as baselines, Isolation Forest mechanics, One-Class SVM and
LocalOutlierFactor in brief, evaluation without (and with rare) labels; week consolidation mini-project.

## 🎯 Learning Goals
1. Distinguish point / contextual / collective anomalies with an example each.
2. Explain Isolation Forest mechanically: random splits isolate anomalies in FEWER cuts → short average
   path length = anomalous. (Trees again — Week A pays off in an unsupervised costume.)
3. Set and interpret `contamination`; understand scores vs binary flags; threshold trade-offs = Week 5's
   precision/recall story with no labels to lean on.
4. Evaluate honestly: with a few known anomalies → precision@k; with none → score distribution + manual
   review of top-k (the realistic case).
5. Mini-project: full unsupervised workflow on one dataset, written up in Week-8 defense style.

## 🔍 Core Mechanics
- IsolationForest path length: expected ~log(n) for normal points; anomalies isolate near the root.
  Aggregate over trees → robust score. No distances → no scaling worry (rare in this week!).
- LOF: density relative to neighbors' density (a point in a sparse region NEAR a dense cluster is the target).
- Score → decision needs a threshold; contamination just sets it via quantile — make that explicit, never magic.

## 🛠️ Build in the paired .py — Mini-project: "Segment & Screen"
On one tabular dataset (Titanic numerics, or a credit/synthetic set with injected anomalies):
1. Inject 2% synthetic anomalies (shifted copies) → ground truth for evaluation.
2. Baselines: z-score and IQR flags (Week-4 functions, reused).
3. IsolationForest + LOF: score distributions, precision@k vs the baselines, overlap analysis (Venn of flags).
4. Cluster the data (k from Day 2 protocol); profile clusters with group-by stats; UMAP map painted by cluster + anomaly flags.
5. `weekC_writeup.md`: question → method choices (with Day 1–6 evidence) → findings → "what I cannot claim" section
   (the unsupervised defense's most important section).

## ⚠️ Common Mistakes
Contamination set arbitrarily then reported as discovered truth · evaluating on the anomalies you injected
WITHOUT noting they're easy/synthetic · skipping manual inspection of flagged rows.
