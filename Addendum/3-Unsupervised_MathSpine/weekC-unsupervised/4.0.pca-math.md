# Week C — Day 4: PCA — The Math (Variance, Eigenvectors, Projections)
> Pairs with `4.1.pca-math.py` · THE day this module exists for. Requires Week D Days 4–5 if eigen-rust has set in — do them first if needed.

## 📚 Topics
Variance maximization view, covariance matrix, eigenvectors/eigenvalues as principal directions,
projection, explained variance ratio, PCA as rotation; SVD as the actual computation.

## 🎯 Learning Goals
1. State PCA's goal two equivalent ways: (a) directions of max variance, (b) best low-rank reconstruction (min squared error).
2. Walk the pipeline by hand: center data → covariance C = XᵀX/(n−1) → eigendecompose C → sort by eigenvalue →
   project X onto top-k eigenvectors.
3. Interpret eigenvalue λᵢ = variance along component i; explained_variance_ratio = λᵢ/Σλ.
4. Explain WHY eigenvectors: maximizing wᵀCw subject to ‖w‖=1 → Lagrange → Cw = λw (do this derivation slowly, once).
5. Know that sklearn uses SVD on centered X directly (numerically better) and how singular values relate: λᵢ = sᵢ²/(n−1).

## 🔍 Core Mechanics
- PCA is a ROTATION into axes where the covariance matrix becomes diagonal — "decorrelating" the features.
  Connect to Week-4 multicollinearity: PCA is what VIF wished it could do.
- Scaling decision matters MORE here than anywhere: PCA on unscaled data = "direction of biggest units".
  Standardize first (correlation-matrix PCA) unless units are genuinely comparable.
- Components are linear combos of original features → loadings tell you what each component "means" (sometimes).

## 🛠️ Build in the paired .py
1. PCA from scratch on a 2-D correlated Gaussian: compute covariance, eigendecompose (`np.linalg.eigh`),
   plot data + both eigenvectors scaled by √λ — the classic ellipse-with-arrows figure.
2. Verify against sklearn PCA: components match up to sign.
3. Scree plot + cumulative explained variance on Titanic numerics (scaled vs unscaled — show the distortion).
4. Reconstruction: project to k=1, reconstruct, plot original vs reconstructed points; compute reconstruction MSE vs k.
5. Verify the SVD route: `np.linalg.svd(X_centered)` → same components, λᵢ = sᵢ²/(n−1).

## ⚠️ Common Mistakes
Skipping centering (everything breaks silently) · reading component SIGN as meaningful (it's arbitrary) ·
keeping "enough components for 95% variance" as ritual without asking what the variance is FOR.
