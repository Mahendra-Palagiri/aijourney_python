# Week C — Day 5: PCA in Practice — Compression, Visualization, Pipelines
> Pairs with `5.1.pca-practice-pipelines.py`

## 📚 Topics
PCA for visualization, PCA as preprocessing inside a supervised pipeline, image compression demo,
whitening, when PCA hurts.

## 🎯 Learning Goals
1. Use PCA(2) honestly for visualization: always annotate axes with explained-variance %, never read
   distances between far clusters too literally.
2. Put PCA INSIDE a Pipeline + CV (it's a fit-on-train transformer like any scaler — Week-7 law applies);
   tune n_components as a hyperparameter.
3. Run the classic eigen-images demo: PCA on digit/face images; view components AS images; reconstruct at
   several k — compression made visceral.
4. Know when PCA hurts supervised tasks: variance ≠ predictiveness (a low-variance direction can carry the label).
5. Understand whitening (scale components to unit variance) and when it's wanted (downstream distance methods).

## 🛠️ Build in the paired .py
1. Scatter Titanic in PC1–PC2 colored by survival; loadings table → name PC1 and PC2 in plain English.
2. Pipeline(StandardScaler → PCA(k) → LogisticRegression): CV over k ∈ {2,…,all}; plot score vs k; compare to no-PCA baseline.
3. Eigen-digits: PCA on sklearn `load_digits`; show top-16 components as 8×8 images; reconstruct one digit at k=5/15/40.
4. Construct the adversarial case: synthetic data where the label lives along the SMALLEST-variance direction;
   show PCA(1) destroys the signal — the warning shot.

## ⚠️ Common Mistakes
PCA fit on full data before split (leakage, again) · treating PC scatter cluster gaps as significant ·
whitening by default (it amplifies noise components).
