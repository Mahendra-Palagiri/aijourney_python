

# Week 12 — Mini Capstone: Neural Network Baseline vs CNN Image Classifier

## 🧭 Week Purpose

Week 12 is a mini capstone for the Deep Learning Foundations section.

This week is not a normal theory week and not a continuation of CNNs alone. It is a project-style workflow that consolidates what we learned across Weeks 9, 10, and 11.

We will build one complete image-classification project using PyTorch:

1. Start with a simple neural network baseline.
2. Train and evaluate the baseline.
3. Build a CNN model for the same task.
4. Train and evaluate the CNN.
5. Compare both models.
6. Explain why one model performs better.
7. Write a final retrospective.

The goal is not only to get a working model. The goal is to understand the full workflow from problem framing to model comparison.

---

## 🔗 Connection to Previous Weeks

| Source Week | What We Learned | How Week 12 Uses It |
|---|---|---|
| Week 9 — Neural Network Basics | Layers, neurons, weights, biases, activations, forward pass, loss, gradient descent, backpropagation, training behavior, overfitting | We use these ideas to build and explain the baseline neural network and the CNN |
| Week 10 — PyTorch Basics | Tensors, shapes, autograd, `nn.Module`, `nn.Linear`, losses, optimizers, `DataLoader`, training loop, evaluation loop, `model.train()`, `model.eval()`, `torch.no_grad()` | We use PyTorch to implement the full training and evaluation workflow |
| Week 11 — CNNs | Image tensors, convolution, kernels/filters, pooling, CNN shape flow, CNN model structure | We build the improved image-aware CNN model and compare it with the baseline |

---

## 🧠 Capstone Question

The central question for Week 12 is:

> Does a CNN perform better than a simple fully connected neural network on image classification, and can we explain why?

We are not only asking whether the CNN works.

We are asking whether the CNN adds value compared with a simpler baseline model.

---

## 🧱 Overall Project Flow

```text
1. Frame the project
2. Prepare the image dataset
3. Build the baseline neural network
4. Train and evaluate the baseline
5. Build the CNN model
6. Train and evaluate the CNN
7. Compare baseline vs CNN
8. Write the retrospective
```

Each phase should be small enough to complete in one focused study session.

## 🧠 Core Concept

The baseline model treats the image as a flat list of numbers.

This is not the best way to handle images, but it gives us a simple reference point. If the CNN performs better later, we can explain the improvement more honestly.

Baseline flow:

```text
image → flatten → Linear → ReLU → Linear → logits
```

- Final classifier layer

## 🎯 Learning Goals

- build a small CNN model in PyTorch
- explain how convolution differs from flattening

- explain why pooling is used
- inspect shape changes through the model
- confirm the CNN output shape

## 🧠 Core Concept

The CNN is the improved model because it preserves image structure longer.

Instead of immediately flattening pixels, it learns local spatial patterns first.

CNN flow:

```text
image → Conv2d → ReLU → Pool → Conv2d → ReLU → Pool → Flatten → Linear → logits
```
