## 🧠 Core Concept

A more complex model is not automatically better.

Our expectation before running the comparison was:

```text
The improved image-aware model may perform better because it preserves image structure before classification.
```

Our observed result was different:

```text
The baseline model consistently performed better than the improved image-aware model, even after increasing training up to 50 epochs.
```

This is an important capstone finding.

The correct response is not to force the improved model to win.

The correct response is to register the evidence and explain what happened.

A better model should provide evidence such as:

The most important comparison metric is validation accuracy, because it shows performance on data the model did not train on.

Validation loss is also important because it shows how confident/wrong the model is overall.

## 🧪 Comparison Questions

We should answer:

1. Which model has higher validation accuracy?
2. Which model has lower validation loss?
3. Did both models learn over time?
4. Did one model overfit more than the other?
5. Is the improved model's performance gain large enough to justify extra complexity?
6. Which model should be selected as the final model?

## 🧾 Our Observed Result

Our expectation was that the improved image-aware model might eventually outperform the baseline model because it uses convolution and pooling to preserve image structure.

However, our actual experiment showed a different result.

The baseline model performed better than the improved image-aware model across repeated runs, including longer training up to 50 epochs.

Example observation from the 50-epoch run:

```text
Baseline model:
validation loss ≈ 0.8145
validation accuracy ≈ 0.7218

Improved image-aware model:
validation loss ≈ 0.8340
validation accuracy ≈ 0.6949
```

Based on this evidence, the baseline model is the stronger model in the current experiment.

This does not mean convolutional models are worse in general.

It means this specific improved model architecture, training setup, and hyperparameter choice did not outperform the simpler baseline.

Possible reasons:

```text
the CNN architecture may be too small
the learning rate may not be ideal
the pooling may reduce information too quickly
the classifier head may be too simple
the baseline may be strong enough for this simple dataset
the CNN may need architecture tuning, not just more epochs
```

Our evidence-based conclusion:

```text
The baseline model should be selected for this capstone run because it achieved better validation performance with a simpler architecture.
```

if comparison["improved_val_acc"] > comparison["baseline_val_acc"] and comparison["improved_val_loss"] <= comparison["baseline_val_loss"]:

## ✅ Concept Check Answers

1. We should not assume the improved model is better because architecture alone is not evidence.

   A more complex model must prove that it improves validation performance.

2. Validation accuracy is the most important comparison metric here because it shows how well each model performs on data it did not train on.

3. Training accuracy can be misleading because a model may memorize training data.

   Validation accuracy gives a better view of general behavior.

4. A positive validation accuracy difference means:

   ```text
   improved validation accuracy - baseline validation accuracy > 0
   ```

   So the improved model has higher validation accuracy.

5. A negative validation loss difference means:

   ```text
   improved validation loss - baseline validation loss < 0
   ```

   So the improved model has lower validation loss.

6. We consider model complexity because a more complex model is harder to explain and may require more computation.

   It should provide enough performance benefit to justify that added complexity.

7. The improved model may be overfitting if training accuracy is much higher than validation accuracy, or if training loss keeps decreasing while validation loss gets worse.

8. Both models need the same validation split so the comparison is fair.

   If the validation data differs, the result may reflect data differences instead of model differences.

9. Evidence supporting the improved model would include higher validation accuracy, lower or similar validation loss, and stable training behavior.

10. Evidence supporting the baseline model would include similar or better validation accuracy, similar or lower validation loss, and simpler architecture.

11. Our actual experiment showed that the baseline model performed better than the improved image-aware model.

    Even after increasing training up to 50 epochs, the improved model did not outperform the baseline.

    Therefore, the evidence-based conclusion is to select the baseline model for this capstone run and document that the improved model may need architecture or hyperparameter tuning before it can add value.
