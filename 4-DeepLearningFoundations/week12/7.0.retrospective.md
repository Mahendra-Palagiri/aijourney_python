## 🧾 Final Capstone Summary

In Week 12, we built an end-to-end deep learning workflow using FashionMNIST.

The task was image classification.

Each image belonged to one of 10 classes.

The input shape was:

```text
[batch_size, channels, height, width]
```

For our batches:

```text
[64, 1, 28, 28]
```

We built two models:

```text
Baseline model:
Flatten → Linear → ReLU → Linear

Improved image-aware model:
Conv2d → ReLU → Pool → Conv2d → ReLU → Pool → Flatten → Linear
```

We trained and evaluated both models using the same general workflow:

```text
forward pass
loss calculation
zero gradients
backward pass
optimizer step
validation evaluation
```

Then we compared both models using validation accuracy and validation loss.

---

## 🔍 Our Original Expectation

Our expectation was:

```text
The improved image-aware model may outperform the baseline model because it uses convolution and pooling before flattening.
```

This expectation was reasonable.

A CNN can preserve spatial structure and learn local image patterns such as edges, curves, and shapes.

The baseline model flattens the image immediately, so it loses the original 2D image structure.

Based on architecture alone, the improved model looked more appropriate for image data.

---

## 📌 What Actually Happened

The actual result was different.

The baseline model consistently outperformed the improved image-aware model.

This remained true even after increasing training up to 50 epochs.

Example observation from the 50-epoch run:

```text
Baseline model:
validation loss ≈ 0.8145
validation accuracy ≈ 0.7218

Improved image-aware model:
validation loss ≈ 0.8340
validation accuracy ≈ 0.6949
```

Based on this evidence, the baseline model was selected for this capstone run.

---

## ✅ Final Model Selection

Selected model:

```text
Baseline model
```

Reason:

```text
The baseline model achieved stronger validation performance than the improved image-aware model while using a simpler architecture.
```

This means the improved model did not justify its added complexity in the current setup.

The decision was based on evidence, not on expectation.

---

## 🧠 Why This Result Matters

This result matters because it shows an important machine learning lesson:

```text
More complex does not always mean better.
```

A model must prove its value through evaluation.

The improved model had a better-sounding architecture for images, but the actual validation results did not support selecting it.

So the correct final answer is:

```text
The baseline model is the better model for this specific experiment.
```

Not:

```text
CNNs are worse than baseline models.
```

The result is specific to our dataset, model design, training setup, and hyperparameters.

---

## 🧩 Possible Reasons the Improved Model Underperformed

The improved image-aware model may have underperformed for several reasons:

```text
the CNN architecture may be too small
the learning rate may not be ideal
the pooling layers may reduce spatial information too quickly
the classifier head may be too simple
the baseline may be strong enough for FashionMNIST
the CNN may need better tuning rather than more epochs only
```

Increasing epochs alone did not solve the problem.

That suggests the issue may be architecture or hyperparameter design, not just training duration.

## 🧠 Final Model Defense

The baseline model was selected as the final model for this capstone run.

Although the improved image-aware model was expected to perform better, the validation results did not support that expectation.

The baseline model achieved better validation accuracy and lower validation loss in the observed experiment, including after longer training.

Therefore, the baseline model is easier to defend because it produced stronger validation performance with less complexity.

The improved model may still be useful after architecture or hyperparameter tuning, but in the current setup, it did not add enough value to justify selection.
