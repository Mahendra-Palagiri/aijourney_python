# 2. 🧱 Why We Need `nn.Module`

A neural network usually has many parts:

```text
input layer
hidden layers
activation functions
output layer
parameters
forward logic
```

If we try to manage all of this manually, the code quickly becomes messy.

PyTorch gives us `nn.Module` as the standard way to define models.

A model class based on `nn.Module` lets us group together:

```text
layers
parameters
forward computation
```

So instead of managing weights and biases manually, we define a model object.

That model object knows:

```text
what layers it has
which parameters are trainable
how data flows through the model
```

This is why most PyTorch models are written as classes that inherit from `nn.Module`.

# 4. 🔢 What `nn.Linear` Does

A linear layer applies this kind of calculation:

```text
output = input × weights + bias
```

In PyTorch, we create a linear layer like this:

```python
layer = nn.Linear(in_features=2, out_features=3)
```

This means:

```text
take 2 input features
produce 3 output values
```

If the input tensor has shape:

```text
[4, 2]
```

that means:

```text
4 samples
2 features per sample
```

The layer:

```python
nn.Linear(2, 3)
```

produces output shape:

```text
[4, 3]
```

because each sample is transformed from 2 values into 3 values.

The batch size stays the same.

The feature dimension changes.

```text
[4, 2] → Linear(2, 3) → [4, 3]
```

<br>

---

<br>

# 5. 📦 Parameters: Weights and Biases

A linear layer has trainable parameters.

Example:

```python
import torch
from torch import nn

layer = nn.Linear(2, 3)

print(layer.weight)
print(layer.bias)
```

The layer has:

```text
weight
bias
```

For:

```python
nn.Linear(2, 3)
```

The weight shape is usually:

```text
[3, 2]
```

The bias shape is:

```text
[3]
```

Why?

Because the layer produces 3 output values, and each output value needs weights for 2 input features.

So conceptually:

```text
3 output neurons
2 input weights per neuron
```

That gives:

```text
3 × 2 weights
```

And each output neuron also has one bias.

So:

```text
3 biases
```

# 6. 🔎 Inspecting Layer Parameters

We can inspect the parameters of a layer:

```python
for name, param in layer.named_parameters():
    print(name)
    print(param)
    print(param.shape)
```

Expected names:

```text
weight
bias
```

These parameters have `requires_grad=True` by default.

That means PyTorch will calculate gradients for them during training.

This is important.

We usually do not manually create model weights like this:

```python
w = torch.tensor(..., requires_grad=True)
```

Instead, PyTorch layers create and manage trainable parameters for us.

# 7. 🏗️ Defining a Model With `nn.Module`

Now we define a simple model class.

```python
import torch
from torch import nn

class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)
```

Let’s break this down carefully.

<br>

## 7.1 🧩 Class Definition

```python
class SimpleRegressionModel(nn.Module):
```

This means:

```text
Create a model class that inherits from nn.Module.
```

Inheriting from `nn.Module` gives the model PyTorch model behavior.

That includes:

```text
parameter tracking
training/eval mode support
state saving/loading support
module nesting
```

<br>

---

<br>

## 7.2 ⚙️ `__init__()`

```python
def __init__(self):
    super().__init__()
    self.linear = nn.Linear(2, 1)
```

The `__init__()` method defines the model’s layers.

This line is required:

```python
super().__init__()
```

It initializes the parent `nn.Module` machinery.

Then:

```python
self.linear = nn.Linear(2, 1)
```

creates one linear layer.

It means:

```text
take 2 input features
produce 1 output value
```

This is useful for a simple regression-style prediction where each sample gets one predicted number.

<br>

---

<br>

## 7.3 ➡️ `forward()`

```python
def forward(self, x):
    return self.linear(x)
```

The `forward()` method defines how data flows through the model.

In this simple model:

```text
input x → linear layer → output
```

So when input data goes into the model, the model applies the linear layer and returns the result.

# 9. ❓ Why `model(X)` Instead of `model.forward(X)`?

We usually call:

```python
predictions = model(X)
```

not:

```python
predictions = model.forward(X)
```

Why?

Because `nn.Module` has special internal behavior around the call.

When we call:

```python
model(X)
```

PyTorch internally calls `forward()`, but it also handles module hooks and other framework behavior.

So the standard PyTorch pattern is:

```python
output = model(input_data)
```

Even though we define `forward()`, we usually do not call it directly.

# 10. 📉 Loss Functions

A model prediction alone is not enough.

We need a way to measure error.

That is the role of a loss function.

For simple regression, one common loss is mean squared error:

```python
loss_fn = nn.MSELoss()
```

MSE means:

```text
mean squared error
```

It compares predictions to actual target values.

Example target tensor:

```python
y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0]
])
```

Shape:

```text
[4, 1]
```

This matches the prediction shape:

```text
[4, 1]
```

Now compute loss:

```python
loss = loss_fn(predictions, y)
print(loss)
```

The loss is a single tensor value.

It tells us how far the model predictions are from the target values.

<br>

# 11. 🚀 Optimizers

A loss function measures error.

An optimizer updates model parameters to reduce that error.

For Day 4, we can use stochastic gradient descent:

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

This means:

```text
Use SGD to update the model's trainable parameters.
Use learning rate 0.01.
```

The key part is:

```python
model.parameters()
```

This gives the optimizer access to the model’s trainable weights and biases.

The optimizer does not update random tensors.

It updates the parameters we give it.

<br>

<br>

# 12. 🔄 One Full Training Step

A single training step looks like this:

```python
optimizer.zero_grad()

predictions = model(X)
loss = loss_fn(predictions, y)

loss.backward()
optimizer.step()
```

Let’s explain each step.

<br>

## 12.1 🧹 Clear Old Gradients

```python
optimizer.zero_grad()
```

From Day 3, we know gradients accumulate by default.

So before computing new gradients, we clear old gradients.

<br>

## 12.2 ➡️ Forward Pass

```python
predictions = model(X)
```

The input data flows through the model.

This produces predictions.

<br>

## 12.3 📉 Compute Loss

```python
loss = loss_fn(predictions, y)
```

The loss compares predictions to actual target values.

<br>

## 12.4 ⬅️ Backward Pass

```python
loss.backward()
```

PyTorch computes gradients of the loss with respect to the model parameters.

<br>

## 12.5 🛠️ Update Parameters

```python
optimizer.step()
```

The optimizer updates weights and biases using the gradients.

<br>

The full pattern is:

```text
zero_grad → forward → loss → backward → step
```

This is the practical PyTorch version of the training loop we learned conceptually in Week 9.

<br>

---

<br>

# 13. 🔍 Inspecting Parameter Gradients

After calling:

```python
loss.backward()
```

we can inspect the gradients:

```python
for name, param in model.named_parameters():
    print(name)
    print("value:", param)
    print("grad:", param.grad)
```

Before `.backward()`, gradients are usually:

```text
None
```

After `.backward()`, gradients contain values.

Those gradients tell the optimizer how to update each parameter.

After:

```python
optimizer.step()
```

parameter values change.

That is training.

# 15. 💻 Full Practice Code

```python
import torch
from torch import nn

# --------------------------------------------------
# 1. Define a simple model
# --------------------------------------------------

class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)


# --------------------------------------------------
# 2. Create input data and targets
# --------------------------------------------------

X = torch.tensor([
    [8.0, 2.0],
    [4.0, 7.0],
    [6.0, 1.0],
    [3.0, 9.0]
])

y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0]
])

print("Input X shape:", X.shape)
print("Target y shape:", y.shape)
print()

# --------------------------------------------------
# 3. Create model, loss function, and optimizer
# --------------------------------------------------

model = SimpleRegressionModel()
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

print("Model:")
print(model)
print()

# --------------------------------------------------
# 4. Inspect initial parameters
# --------------------------------------------------

print("Initial parameters:")
for name, param in model.named_parameters():
    print(name)
    print("value:", param)
    print("requires_grad:", param.requires_grad)
    print("shape:", param.shape)
    print()

# --------------------------------------------------
# 5. Forward pass
# --------------------------------------------------

predictions = model(X)
print("Predictions before training step:")
print(predictions)
print("Predictions shape:", predictions.shape)
print()

# --------------------------------------------------
# 6. Compute loss
# --------------------------------------------------

loss = loss_fn(predictions, y)
print("Loss before training step:", loss)
print()

# --------------------------------------------------
# 7. Backward pass
# --------------------------------------------------

optimizer.zero_grad()
loss.backward()

print("Gradients after backward:")
for name, param in model.named_parameters():
    print(name)
    print("grad:", param.grad)
    print()

# --------------------------------------------------
# 8. Optimizer step
# --------------------------------------------------

optimizer.step()

print("Parameters after optimizer.step():")
for name, param in model.named_parameters():
    print(name)
    print("value:", param)
    print()

# --------------------------------------------------
# 9. Forward pass after one update
# --------------------------------------------------

new_predictions = model(X)
new_loss = loss_fn(new_predictions, y)

print("Predictions after one training step:")
print(new_predictions)
print("Loss after one training step:", new_loss)
```

# 17. ✅ Answer Key

## Answer 1

`nn.Module` helps us organize:

```text
layers
parameters
forward computation
model behavior
```

It is the standard PyTorch base class for building models.

<br>

## Answer 2

```python
nn.Linear(2, 1)
```

means:

```text
2 input features
1 output value
```

So an input shape of `[batch_size, 2]` becomes `[batch_size, 1]`.

<br>

## Answer 3

Weights and biases need gradients because the optimizer uses gradients to update them.

Gradients tell us:

```text
how changing each parameter affects the loss
```

Without gradients, the optimizer would not know how to improve the model.

<br>

## Answer 4

The `forward()` method defines how data flows through the model.

For example:

```text
input → linear layer → output
```

In larger models, it may define several layers and activations.

<br>

## Answer 5

We call:

```python
model(X)
```

because PyTorch’s `nn.Module` call mechanism invokes `forward()` while also preserving framework behavior such as hooks and internal module handling.

The standard PyTorch pattern is:

```python
output = model(input_data)
```

<br>

## Answer 6

The loss function measures how far predictions are from the target values.

For example, `nn.MSELoss()` computes mean squared error for regression-style problems.

<br>

## Answer 7

The optimizer updates model parameters using gradients.

Example:

```python
optimizer.step()
```

updates weights and biases after `.backward()` has computed gradients.

<br>

## Answer 8

The correct order is:

```text
optimizer.zero_grad()
predictions = model(X)
loss = loss_fn(predictions, y)
loss.backward()
optimizer.step()
```

Conceptually:

```text
clear old gradients → forward pass → compute loss → backward pass → update parameters
```
