# 3. 🔢 Step 1: Create Feature and Target Tensors

We start with a tiny regression-style dataset.

Each input sample has two features.

Each target has one output value.

```python
import torch

X = torch.tensor([
    [8.0, 2.0],
    [4.0, 7.0],
    [6.0, 1.0],
    [3.0, 9.0],
    [9.0, 4.0],
    [2.0, 6.0],
    [7.0, 3.0],
    [5.0, 8.0]
])

y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0],
    [28.0],
    [26.0],
    [21.0],
    [35.0]
])
```

Shapes:

```text
X.shape = [8, 2]
y.shape = [8, 1]
```

Meaning:

```text
8 samples
2 features per sample
1 target value per sample
```

The model we build must accept 2 input features and produce 1 output value.

# 4. 📦 Step 2: Create `TensorDataset`

Now we pair input rows with matching target rows.

```python
from torch.utils.data import TensorDataset

dataset = TensorDataset(X, y)
```

This creates sample pairs:

```text
sample 0 → X[0], y[0]
sample 1 → X[1], y[1]
sample 2 → X[2], y[2]
...
```

Check the dataset length:

```python
print(len(dataset))
```

Expected output:

```text
8
```

Inspect one sample:

```python
features, target = dataset[0]
print(features)
print(target)
```

Expected output:

```text
tensor([8., 2.])
tensor([20.])
```

# 5. 🚚 Step 3: Create `DataLoader`

Now we create batches.

```python
from torch.utils.data import DataLoader

loader = DataLoader(dataset, batch_size=2, shuffle=True)
```

This means:

```text
2 samples per batch
shuffle training samples before batching
```

Since we have 8 samples and batch size 2:

```text
8 samples ÷ batch size 2 = 4 batches per epoch
```

Each `batch_X` should have shape:

```text
[2, 2]
```

Each `batch_y` should have shape:

```text
[2, 1]
```

# 6. 🏗️ Step 4: Define the Model

We define a simple regression model.

```python
from torch import nn

class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)
```

This model has one linear layer:

```python
nn.Linear(2, 1)
```

Meaning:

```text
2 input features
1 output value
```

So:

```text
[batch_size, 2] → [batch_size, 1]
```

Create the model:

```python
model = SimpleRegressionModel()
```

<br>

# 7. 📉 Step 5: Choose Loss Function

For this regression-style example, we use mean squared error:

```python
loss_fn = nn.MSELoss()
```

The loss function compares:

```text
predictions
target values
```

and returns one error value.

This error value is what `.backward()` uses to compute gradients.

<br>

---

<br>

# 8. 🚀 Step 6: Choose Optimizer

The optimizer updates the model parameters.

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)
```

This means:

```text
Use SGD optimizer.
Update model parameters.
Use learning rate 0.001.
```

We use a smaller learning rate here to keep the tiny example more stable.

The optimizer receives:

```python
model.parameters()
```

So it knows which weights and biases to update.

<br>

---

<br>

# 9. 🔄 Step 7: Write the Training Loop

A training loop has two levels:

```text
outer loop: epochs
inner loop: batches
```

Example:

```python
num_epochs = 20

for epoch in range(num_epochs):
    total_loss = 0.0

    for batch_X, batch_y in loader:
        optimizer.zero_grad()

        predictions = model(batch_X)
        loss = loss_fn(predictions, batch_y)

        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    average_loss = total_loss / len(loader)
    print(f"Epoch {epoch + 1}/{num_epochs}, average loss: {average_loss:.4f}")
```

The inner loop performs one training step per batch.

The full training-step sequence is:

```text
zero_grad → forward → loss → backward → step
```

# 10. 🧮 What `loss.item()` Means

The loss returned by PyTorch is a tensor.

Example:

```python
loss = loss_fn(predictions, batch_y)
```

This might look like:

```text
tensor(123.4567, grad_fn=<MseLossBackward0>)
```

When we call:

```python
loss.item()
```

we extract the plain Python number from the tensor.

This is useful for logging.

We do not use `.item()` for backpropagation.

We use the tensor loss for:

```python
loss.backward()
```

We use `loss.item()` only for tracking or printing.

<br>

---

<br>

# 11. 📊 Step 8: Track Average Loss Per Epoch

Inside each epoch, multiple batches produce multiple loss values.

Example:

```text
batch 1 loss
batch 2 loss
batch 3 loss
batch 4 loss
```

We add them:

```python
total_loss += loss.item()
```

Then compute the average:

```python
average_loss = total_loss / len(loader)
```

Since `len(loader)` is the number of batches, this gives average batch loss for the epoch.

The purpose is to observe whether the model is generally improving over epochs.

<br>

<br>

# 12. 🧪 Step 9: Evaluation Mode

After training, we evaluate the model.

For evaluation, we usually use:

```python
model.eval()
```

This tells PyTorch the model is in evaluation mode.

For this simple linear model, `model.eval()` does not change much.

But for models with layers like dropout or batch normalization, it matters.

So we should build the habit early.

<br>

---

<br>

# 13. 🚫 Step 10: Disable Gradient Tracking During Evaluation

During evaluation, we do not update weights.

So we do not need gradients.

Use:

```python
with torch.no_grad():
    final_predictions = model(X)
    final_loss = loss_fn(final_predictions, y)
```

This saves memory and computation.

It also prevents PyTorch from building an unnecessary computation graph.

Common evaluation pattern:

```python
model.eval()

with torch.no_grad():
    predictions = model(X)
```

<br>

---

<br>

# 14. 🔁 Returning to Training Mode

If we train again after evaluation, we should call:

```python
model.train()
```

This puts the model back into training mode.

For simple models, this may not visibly change behavior.

But for larger neural networks, it matters.

Common pattern:

```python
model.train()
# training loop

model.eval()
with torch.no_grad():
    # evaluation
```

# 15. 💻 Full Practice Code

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

# --------------------------------------------------
# 1. Create input features and target values
# --------------------------------------------------

X = torch.tensor([
    [8.0, 2.0],
    [4.0, 7.0],
    [6.0, 1.0],
    [3.0, 9.0],
    [9.0, 4.0],
    [2.0, 6.0],
    [7.0, 3.0],
    [5.0, 8.0]
])

y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0],
    [28.0],
    [26.0],
    [21.0],
    [35.0]
])

print("X shape:", X.shape)
print("y shape:", y.shape)
print()

# --------------------------------------------------
# 2. Create TensorDataset and DataLoader
# --------------------------------------------------

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=2, shuffle=True)

print("Dataset length:", len(dataset))
print("Number of batches per epoch:", len(loader))
print()

# --------------------------------------------------
# 3. Inspect one batch
# --------------------------------------------------

batch_X, batch_y = next(iter(loader))

print("One batch_X:")
print(batch_X)
print("batch_X shape:", batch_X.shape)
print()

print("One batch_y:")
print(batch_y)
print("batch_y shape:", batch_y.shape)
print()

# --------------------------------------------------
# 4. Define model
# --------------------------------------------------

class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)


model = SimpleRegressionModel()

print("Model:")
print(model)
print()

# --------------------------------------------------
# 5. Define loss function and optimizer
# --------------------------------------------------

loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)

# --------------------------------------------------
# 6. Predictions before training
# --------------------------------------------------

model.eval()
with torch.no_grad():
    initial_predictions = model(X)
    initial_loss = loss_fn(initial_predictions, y)

print("Predictions before training:")
print(initial_predictions)
print("Initial loss:", initial_loss.item())
print()

# --------------------------------------------------
# 7. Train model
# --------------------------------------------------

model.train()

num_epochs = 20

for epoch in range(num_epochs):
    total_loss = 0.0

    for batch_X, batch_y in loader:
        optimizer.zero_grad()

        predictions = model(batch_X)
        loss = loss_fn(predictions, batch_y)

        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    average_loss = total_loss / len(loader)

    print(f"Epoch {epoch + 1}/{num_epochs}, average loss: {average_loss:.4f}")

# --------------------------------------------------
# 8. Evaluate after training
# --------------------------------------------------

model.eval()
with torch.no_grad():
    final_predictions = model(X)
    final_loss = loss_fn(final_predictions, y)

print()
print("Predictions after training:")
print(final_predictions)
print("Final loss:", final_loss.item())
```
