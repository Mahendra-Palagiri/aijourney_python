# 1. 🔁 Review From Day 4

In Day 4, we connected autograd to actual PyTorch models.

The key training-step pattern was:

```text
zero_grad → forward → loss → backward → step
```

In code:

```python
optimizer.zero_grad()

loss = loss_fn(predictions, y)

```

This works, but it uses the full tensor `X` at once.

For tiny examples, that is fine.

For real datasets, we usually do not manually pass the entire dataset every time.

Instead, we use batches.

PyTorch helps us create and manage batches with:

```python
Dataset
```

# 2. 🧠 Why We Need Data Pipelines

In real machine learning, datasets can be large.

Examples:

```text
10,000 tabular rows
100,000 images
millions of text samples
```

Feeding all data at once can be inefficient or impossible because of memory limits.

Instead, we train using small chunks of data called batches.

A batch is a small group of samples.

Example:

```text
Dataset size = 1,000 samples
Batch size = 100
Number of batches = 10
```

During training, the model processes one batch at a time.

Each batch gets its own:

```text
forward pass
loss calculation
backward pass
optimizer update
```

This is why a training loop often has two levels:

```text
for each epoch:
    for each batch:
        train on that batch
```

# 3. 📦 What a `Dataset` Represents

A PyTorch `Dataset` represents a collection of examples.

Each example usually contains:

```text
input features
matching target value
```

For supervised learning, each sample is commonly a pair:

```text
(X_row, y_value)
```

Example:

```text
features: [8.0, 2.0]
target:   [20.0]
```

A dataset’s job is to answer:

```text
How many samples are there?
What is sample number i?
```

A custom `Dataset` normally implements:

```python
__len__()
__getitem__()
```

But before writing custom datasets, PyTorch gives us a simple ready-made option for tensors:

```python
TensorDataset
```

# 4. 🔗 What `TensorDataset` Does

`TensorDataset` pairs tensors together sample by sample.

First, create feature and target tensors:

```python
import torch
from torch.utils.data import TensorDataset

X = torch.tensor([
    [8.0, 2.0],
    [4.0, 7.0],
    [6.0, 1.0],
    [3.0, 9.0]
])

y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0]
])
```

Shapes:

```text
X.shape = [4, 2]
y.shape = [4, 1]
```

This means:

```text
4 input samples
4 matching target values
```

Now create a dataset:

```python
dataset = TensorDataset(X, y)
```

This pairs each row of `X` with the matching row of `y`.

Conceptually:

```text
sample 0 → X[0], y[0]
sample 1 → X[1], y[1]
sample 2 → X[2], y[2]
sample 3 → X[3], y[3]
```

# 5. 🔍 Inspecting a `TensorDataset`

We can check the length:

```python
print(len(dataset))
```

Output:

```text
4
```

We can inspect one sample:

```python
features, target = dataset[0]

print(features)
print(target)
```

Output:

```text
tensor([8., 2.])
tensor([20.])
```

This means:

```text
first input row = [8.0, 2.0]
first target row = [20.0]
```

So `TensorDataset` makes the relationship between inputs and targets explicit.

# 6. 🚚 What `DataLoader` Does

A `Dataset` stores or represents samples.

A `DataLoader` controls how we retrieve those samples during training.

It can handle:

```text
batching
shuffling
iteration
```

Create a `DataLoader`:

```python
from torch.utils.data import DataLoader

loader = DataLoader(dataset, batch_size=2, shuffle=True)
```

This means:

```text
Give us 2 samples per batch.
Shuffle the data before batching.
```

<br>

# 7. 🧺 Understanding `batch_size`

`batch_size` controls how many samples are included in one batch.

Example:

```python
loader = DataLoader(dataset, batch_size=2, shuffle=False)
```

Our dataset has 4 samples.

With batch size 2:

```text
batch 1 → 2 samples
batch 2 → 2 samples
```

So one full pass through this dataset creates 2 batches.

If we used:

```python
batch_size=4
```

then one batch would contain all 4 samples.

If we used:

```python
batch_size=1
```

then each batch would contain one sample.

<br>

---

<br>

# 8. 🔀 Understanding `shuffle=True`

For training data, we usually use:

```python
shuffle=True
```

This randomizes the sample order before creating batches.

Why does this help?

If the data is ordered in a pattern, the model may see biased batches.

Example:

```text
first 100 samples → class 0
next 100 samples  → class 1
```

Without shuffling, early batches may contain only one class.

With shuffling, each batch is more likely to contain a better mixture.

For validation or testing, we usually use:

```python
shuffle=False
```

because evaluation should be stable and repeatable.

# 9. 🔁 Iterating Through a `DataLoader`

A `DataLoader` can be used in a loop.

```python
for batch_X, batch_y in loader:
    print(batch_X)
    print(batch_y)
    print(batch_X.shape)
    print(batch_y.shape)
```

If:

```python
batch_size=2
```

then each `batch_X` should have shape:

```text
[2, 2]
```

because:

```text
2 samples per batch
2 features per sample
```

Each `batch_y` should have shape:

```text
[2, 1]
```

because:

```text
2 target values per batch
1 target value per sample
```

# 10. 📆 Training Step vs Epoch

This distinction is important.

A training step is one parameter update.

An epoch is one full pass through the training dataset.

Example:

```text
Dataset size = 4 samples
Batch size = 2
```

Then:

```text
1 epoch = 2 batches
2 batches = 2 training steps
```

So one epoch can contain multiple training steps.

In Day 4, we passed the whole tiny dataset at once.

That was effectively one full-batch training step.

In Day 5, we use `DataLoader`, so we can see the more realistic structure:

```text
for each epoch:
    for each batch:
        one training step
```

# 11. 🔄 Connecting `DataLoader` to Training

From Day 4, one training step was:

```python
optimizer.zero_grad()
predictions = model(X)
loss = loss_fn(predictions, y)
loss.backward()
optimizer.step()
```

With `DataLoader`, we apply the same logic to each batch:

```python
for batch_X, batch_y in loader:
    optimizer.zero_grad()
    predictions = model(batch_X)
    loss = loss_fn(predictions, batch_y)
    loss.backward()
    optimizer.step()
```

The pattern is unchanged.

Only the input changes:

```text
Day 4: full X
Day 5: batch_X
```

# 13. 💻 Full Practice Code

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

# --------------------------------------------------
# 1. Create input features and target values
# --------------------------------------------------

X = torch.tensor([
    [8.0, 2.0],
    [4.0, 7.0],
    [6.0, 1.0],
    [3.0, 9.0]
])

y = torch.tensor([
    [20.0],
    [30.0],
    [15.0],
    [40.0]
])

print("X shape:", X.shape)
print("y shape:", y.shape)
print()

# --------------------------------------------------
# 2. Create TensorDataset
# --------------------------------------------------

dataset = TensorDataset(X, y)

print("Dataset length:", len(dataset))

first_features, first_target = dataset[0]
print("First sample features:", first_features)
print("First sample target:", first_target)
print()

# --------------------------------------------------
# 3. Create DataLoader
# --------------------------------------------------

loader = DataLoader(dataset, batch_size=2, shuffle=True)

print("Batches from DataLoader:")
for batch_index, (batch_X, batch_y) in enumerate(loader):
    print("Batch:", batch_index)
    print("batch_X:")
    print(batch_X)
    print("batch_y:")
    print(batch_y)
    print("batch_X shape:", batch_X.shape)
    print("batch_y shape:", batch_y.shape)
    print()

# --------------------------------------------------
# 4. Define simple model
# --------------------------------------------------

class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)


model = SimpleRegressionModel()
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# --------------------------------------------------
# 5. Train for a few epochs
# --------------------------------------------------

num_epochs = 5

for epoch in range(num_epochs):
    total_loss = 0.0

    for batch_X, batch_y in loader:
        optimizer.zero_grad()

        predictions = model(batch_X)
        loss = loss_fn(predictions, batch_y)

        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    average_loss = total_loss / len(loader)

    print(f"Epoch {epoch + 1}/{num_epochs}, average loss: {average_loss:.4f}")

# --------------------------------------------------
# 6. Inspect final predictions
# --------------------------------------------------

with torch.no_grad():
    final_predictions = model(X)
    final_loss = loss_fn(final_predictions, y)

print()
print("Final predictions:")
print(final_predictions)
print("Final loss:", final_loss.item())
```
