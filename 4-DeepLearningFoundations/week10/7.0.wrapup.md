# 2. 🧠 The Full PyTorch Mental Model

The complete workflow can be summarized as:

```text
tensors → dataset → dataloader → model → predictions → loss → backward → optimizer step → evaluation
```

**Explanation:**
- Start with raw data as tensors.
- Organize data into a `Dataset`.
- Use a `DataLoader` to batch and shuffle data.
- Pass batches through a model (`nn.Module`) to get predictions.
- Compute a loss comparing predictions to targets.
- Run `.backward()` to compute gradients.
- Use the optimizer to update model parameters.
- Switch to evaluation mode to assess model performance.

# 7. 🔍 Baseline Evaluation Before Training

Before training, we check how the untrained model performs:

```python
model.eval()
with torch.no_grad():
    preds = model(X)
    initial_loss = loss_fn(preds, y)
print("Initial loss:", initial_loss.item())
```

- `model.eval()` sets the model to evaluation mode (important for layers like dropout/batchnorm).
- `torch.no_grad()` disables gradient tracking, saving memory and computation.

# 8. 🔄 Training Loop

```python
num_epochs = 50
for epoch in range(num_epochs):
    model.train()
    total_loss = 0.0
    for batch_X, batch_y in loader:
        optimizer.zero_grad()
        predictions = model(batch_X)
        loss = loss_fn(predictions, batch_y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    average_loss = total_loss / len(loader)
    if (epoch+1) % 10 == 0 or epoch == 0:
        print(f"Epoch {epoch+1}/{num_epochs} - Loss: {average_loss:.4f}")
```

- `model.train()` ensures the model is in training mode.
- Zero gradients before each step.
- Forward pass, compute loss, backward pass, optimizer step.
- Track average loss per epoch for monitoring.

# 10. 💻 Full Final Practice Code

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(42)

# Data setup
X = torch.randn(8, 2)
y = torch.randn(8, 1)
print("X shape:", X.shape)
print("y shape:", y.shape)

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=2, shuffle=True)

# Model definition
class SimpleRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 4),
            nn.ReLU(),
            nn.Linear(4, 1)
        )
    def forward(self, x):
        return self.net(x)

model = SimpleRegressionModel()
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)

# Baseline evaluation
model.eval()
with torch.no_grad():
    preds = model(X)
    initial_loss = loss_fn(preds, y)
print("Initial loss:", initial_loss.item())

# Training loop
num_epochs = 50
for epoch in range(num_epochs):
    model.train()
    total_loss = 0.0
    for batch_X, batch_y in loader:
        optimizer.zero_grad()
        predictions = model(batch_X)
        loss = loss_fn(predictions, batch_y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    average_loss = total_loss / len(loader)
    if (epoch+1) % 10 == 0 or epoch == 0:
        print(f"Epoch {epoch+1}/{num_epochs} - Loss: {average_loss:.4f}")

# Final evaluation
model.eval()
with torch.no_grad():
    preds = model(X)
    final_loss = loss_fn(preds, y)
print("Final loss:", final_loss.item())
```

# 11. ⚠️ Common Week 10 Mistakes

- **Confusing batch size with feature count:** Remember, batch size is the number of samples per batch, not the number of features.
- **Forgetting `optimizer.zero_grad()`:** Omitting this causes gradients to accumulate across steps.
- **Expecting `.backward()` to update parameters:** `.backward()` computes gradients; `optimizer.step()` actually updates parameters.
- **Using `torch.no_grad()` during training:** This disables gradient tracking—should only be used during evaluation/inference.
- **Forgetting `model.train()` after `model.eval()`:** Always switch back to training mode before training resumes.
- **Mismatching prediction and target shapes:** Ensure model outputs and targets are the same shape for the loss function.
- **Thinking one step equals one epoch:** One step is one batch update; one epoch is a full pass over the dataset.

# 14. ✅ Answer Key

1. **Tensors** are the fundamental data structure in PyTorch, representing multi-dimensional arrays for data and model parameters.
2. **Autograd** automatically tracks operations on tensors and computes gradients for backpropagation.
3. **`nn.Module`** organizes model layers and parameters, providing a consistent interface for forward passes.
4. **`DataLoader`** provides efficient batching, shuffling, and iteration over datasets.
5. **One training step** is one forward and backward pass (and parameter update) on a single batch.
6. **One epoch** is a full pass through the entire training dataset.
7. **`model.eval()`** and **`torch.no_grad()`** ensure the model runs in inference mode and disables gradient tracking, which is important for correct evaluation and efficiency.
8. **`optimizer.step()`** updates model parameters using the gradients computed by `.backward()`.
