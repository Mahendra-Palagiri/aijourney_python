# 2. 🧠 Core Concept: What Convolution Does

A convolution layer looks for local patterns in an image.

Instead of looking at the whole image at once, it looks at small regions.

Example local regions:

```text
3 × 3 patch
5 × 5 patch
```

A convolution layer asks:

```text
Does this small part of the image contain a useful pattern?
```

Examples of useful early patterns:

```text
vertical edge
horizontal edge
corner
curve
texture
```

So the first big idea is:

```text
Convolution converts local image patches into detected pattern scores.
```

<br>

---

<br>

# 3. 🔎 What Is a Filter / Kernel?

A filter, also called a kernel, is a small grid of learnable weights.

Example of a `3 × 3` kernel:

```text
w1  w2  w3
w4  w5  w6
w7  w8  w9
```

These weights are learned during training.

The kernel is not manually designed in most modern CNN training.

The model learns what values should be inside the kernel based on the loss and backpropagation.

So we can think of a kernel as:

```text
a small pattern detector
```

<br>

---

<br>

# 4. 🪟 Sliding Window Intuition

A kernel scans across the image one local patch at a time.

Suppose we have a `3 × 3` kernel.

It first looks at the top-left `3 × 3` region of the image.

Then it shifts right.

Then it shifts right again.

When it reaches the end of the row, it moves down and repeats.

This movement is called a sliding window.

Simple view:

```text
image area scanned by kernel:

[3 × 3 patch] → move right → move right → ...
       ↓
move down
       ↓
[3 × 3 patch] → move right → move right → ...
```

Each local patch produces one output value.

<br>

---

<br>

# 5. 🧮 Local Dot Product Intuition

At each position, the kernel overlaps with a local patch of the image.

Example image patch:

```text
p1  p2  p3
p4  p5  p6
p7  p8  p9
```

Kernel weights:

```text
w1  w2  w3
w4  w5  w6
w7  w8  w9
```

The convolution layer multiplies matching positions and adds them up:

```text
p1*w1 + p2*w2 + p3*w3 +
p4*w4 + p5*w5 + p6*w6 +
p7*w7 + p8*w8 + p9*w9
```

That result becomes one value in the output.

So one output value comes from:

```text
one local image patch + one kernel
```

This is very similar to a dot product.

The difference is that the same small kernel is reused across many image locations.

<br>

---

<br>

# 6. 🧠 Core Concept: One Patch Produces One Output Value

For a `3 × 3` kernel:

```text
one 3 × 3 image patch → one number
```

Then the kernel slides to the next position:

```text
next 3 × 3 image patch → one number
```

After scanning the whole image, we get many output numbers arranged as a new grid.

That new grid is called a feature map.

<br>

---

<br>

# 7. 🗺️ What Is a Feature Map?

A feature map is the output produced by applying one filter across the image.

If a filter detects vertical edges, its feature map tells us:

```text
where vertical edges may exist
```

If a filter detects curves, its feature map tells us:

```text
where curves may exist
```

The feature map preserves location information.

That means the model can still know approximately where a pattern was detected.

This is different from flattening the image immediately.

<br>

<br>

# 8. 🔢 Why Output Size Shrinks With No Padding

Suppose input image size is:

```text
28 × 28
```

Kernel size is:

```text
3 × 3
```

Padding is:

```text
0
```

Stride is:

```text
1
```

The `3 × 3` kernel must fully fit inside the image.

Along one dimension:

```text
output size = input size - kernel size + 1
```

So:

```text
28 - 3 + 1 = 26
```

Therefore:

```text
28 × 28 → 26 × 26
```

This is why a convolution with `kernel_size=3`, `stride=1`, and `padding=0` changes the spatial size from `28 × 28` to `26 × 26`.

<br>

# 9. 🧩 One Filter vs Multiple Filters

One filter creates one feature map.

So if we use:

```text
1 filter
```

we get:

```text
1 output channel
```

If we use:

```text
8 filters
```

we get:

```text
8 output channels
```

Each filter learns to detect a different kind of pattern.

Example:

```text
filter 1 → vertical edges
filter 2 → horizontal edges
filter 3 → curves
filter 4 → corners
...
```

This is why `out_channels` in `nn.Conv2d` means number of filters.

<br>

# 10. 🔗 Connecting to `nn.Conv2d`

Example:

```python
import torch
import torch.nn as nn

images = torch.randn(4, 1, 28, 28)

conv = nn.Conv2d(
    in_channels=1,
    out_channels=8,
    kernel_size=3
)

output = conv(images)

print(output.shape)
```

Expected output:

```text
torch.Size([4, 8, 26, 26])
```

Let us read this carefully:

```text
4  = same batch size
8  = number of filters / output channels
26 = output height
26 = output width
```

So:

```text
[4, 1, 28, 28] → [4, 8, 26, 26]
```

Meaning:

```text
4 input images
1 input channel
8 learned filters
8 output feature maps per image
26 × 26 spatial size per feature map
```

# 11. ⚠️ Important Clarification: The Kernel Has Depth Too

For a grayscale image, the input has one channel:

```text
C = 1
```

So a `3 × 3` kernel is effectively:

```text
1 × 3 × 3
```

For a color image, the input has three channels:

```text
C = 3
```

So a `3 × 3` kernel is effectively:

```text
3 × 3 × 3
```

That means the filter looks across all input channels.

In PyTorch:

```python
nn.Conv2d(in_channels=3, out_channels=8, kernel_size=3)
```

means:

```text
input has 3 channels
create 8 filters
each filter spans all 3 input channels
```

The output channels are controlled by:

```text
out_channels
```

not by the original color channels alone.

# 14. 🔁 Review / Connection

From Week 10, we already know:

```text
model layers contain learnable weights
forward pass creates predictions
loss measures error
backward pass computes gradients
optimizer updates weights
```

A convolution layer follows the same pattern.

The difference is the type of learnable weight.

For `nn.Linear`, weights connect input features to output neurons.

For `nn.Conv2d`, weights act like small filters that scan across image regions.

So:

```text
nn.Linear learns relationships across flattened features.
nn.Conv2d learns local visual patterns through filters.
```
