# 1. 🔁 Review From Day 1

In Day 1, we learned why CNNs exist.

The main idea was:

```text
CNNs are useful because images have local spatial structure.
```

A fully connected network usually flattens an image:

```text

```

That can work, but it weakens the image-grid structure.

A CNN keeps the image structure longer, so it needs the input to retain image dimensions.

That brings us to Day 2:

```text

```

# 2. 🖼️ The Standard PyTorch Image Shape

PyTorch CNN layers usually expect image tensors in this shape:

```text
[N, C, H, W]
```

Meaning:

```text
N = batch size
C = channels
H = height
W = width
```

Example:

```text
[4, 1, 28, 28]
```

Means:

```text
4 images in the batch
1 channel per image
28 pixels high
28 pixels wide
```

This is the most important Day 2 shape pattern.

<br>

---

<br>

# 3. 🧠 Core Concept: Each Dimension Has a Job

A CNN image tensor is not just a random 4D tensor.

Each dimension has a specific meaning.

| Dimension | Name | Meaning |
|---|---|---|
| `N` | Batch size | Number of images processed together |
| `C` | Channels | Number of color/intensity layers |
| `H` | Height | Number of pixel rows |
| `W` | Width | Number of pixel columns |

So this shape:

```text
[16, 3, 64, 64]
```

Means:

```text
16 images
3 channels
64 rows
64 columns
```

This would usually represent a batch of 16 color images.

<br>

# 4. ⚫ Grayscale Image Shape

A grayscale image has one channel.

A single grayscale image of size `28 × 28` has:

```text
C = 1
H = 28
W = 28
```

If we have one image, we still need a batch dimension.

So the shape should be:

```text
[1, 1, 28, 28]
```

Meaning:

```text
1 image in the batch
1 channel
28 height
28 width
```

If we have 32 grayscale images:

```text
[32, 1, 28, 28]
```

Meaning:

```text
32 images in the batch
1 channel per image
28 height
28 width
```

<br>

---

<br>

# 5. 🎨 Color Image Shape

A color image usually has three channels:

```text
Red
Green
Blue
```

So:

```text
C = 3
```

A single color image of size `64 × 64` should be shaped as:

```text
[1, 3, 64, 64]
```

A batch of 10 color images should be shaped as:

```text
[10, 3, 64, 64]
```

Meaning:

```text
10 images
3 channels per image
64 height
64 width
```

<br>

---

<br>

# 6. ⚠️ PyTorch Uses Channel-First Format

PyTorch CNNs usually expect:

```text
[N, C, H, W]
```

This is called channel-first format.

Some image libraries store images as:

```text
[H, W, C]
```

Example:

```text
[64, 64, 3]
```

That means:

```text
height = 64
width = 64
channels = 3
```

But PyTorch `nn.Conv2d` expects the channel dimension before height and width.

So for one image, we usually need:

```text
[1, 3, 64, 64]
```

Not:

```text
[64, 64, 3]
```

This is one of the most common CNN shape bugs.

<br>

---

<br>

# 7. 🔄 Flattening vs Keeping Image Shape

For a fully connected layer, we often flatten:

```text
[batch, channels, height, width] → [batch, features]
```

Example:

```text
[4, 1, 28, 28] → [4, 784]
```

because:

```text
1 × 28 × 28 = 784
```

But for a CNN layer, we do not flatten before convolution.

A convolution layer expects:

```text
[N, C, H, W]
```

So this works conceptually for `nn.Conv2d`:

```text
[4, 1, 28, 28]
```

But this does not fit as image input to `nn.Conv2d`:

```text
[4, 784]
```

because the channel, height, and width dimensions are no longer explicit.

# 9. ➕ Adding a Missing Batch Dimension

Sometimes we may have one grayscale image shaped like this:

```python
image = torch.randn(1, 28, 28)

print(image.shape)
```

Output:

```text
torch.Size([1, 28, 28])
```

This means:

```text
1 channel
28 height
28 width
```

But it is missing the batch dimension.

For `nn.Conv2d`, we need:

```text
[N, C, H, W]
```

So we can add the batch dimension:

```python
image_batch = image.unsqueeze(0)

print(image_batch.shape)
```

Output:

```text
torch.Size([1, 1, 28, 28])
```

Now the shape means:

```text
1 image in the batch
1 channel
28 height
28 width
```

<br>

---

<br>

# 10. ➕ Adding a Missing Channel Dimension

Sometimes we may have one grayscale image shaped like this:

```python
image = torch.randn(28, 28)

print(image.shape)
```

Output:

```text
torch.Size([28, 28])
```

This has height and width, but it is missing:

```text
batch dimension
channel dimension
```

We can add both:

```python
image = image.unsqueeze(0)  # add channel dimension
image = image.unsqueeze(0)  # add batch dimension

print(image.shape)
```

Output:

```text
torch.Size([1, 1, 28, 28])
```

Meaning:

```text
1 image
1 channel
28 height
28 width
```

# 11. 🧪 First `nn.Conv2d` Shape Check

We are not learning convolution math yet.

For now, we only want to see that `nn.Conv2d` expects image-shaped input.

```python
import torch
import torch.nn as nn

images = torch.randn(4, 1, 28, 28)

conv = nn.Conv2d(
    in_channels=1,
    out_channels=8,
    kernel_size=3
)

output = conv(images)

print(output.shape)
```

Expected output:

```text
torch.Size([4, 8, 26, 26])
```

For now, focus only on the first two dimensions:

```text
4 = same batch size
8 = number of filters / output channels
```

The height and width changed from `28 × 28` to `26 × 26` because of the `3 × 3` kernel with no padding.

We will study that more carefully in the next CNN days.

# 12. ⚠️ Common Shape Bugs

## Bug 1: Missing Batch Dimension

Wrong shape:

```text
[1, 28, 28]
```

This has:

```text
channel, height, width
```

But it is missing:

```text
batch size
```

Correct shape:

```text
[1, 1, 28, 28]
```

<br>

## Bug 2: Missing Channel Dimension

Wrong shape:

```text
[4, 28, 28]
```

This may look like:

```text
4 images, 28 height, 28 width
```

But `nn.Conv2d` expects:

```text
[batch, channels, height, width]
```

Correct shape for 4 grayscale images:

```text
[4, 1, 28, 28]
```

<br>

## Bug 3: Channel Last Instead of Channel First

Wrong for PyTorch CNN input:

```text
[4, 28, 28, 1]
```

Correct:

```text
[4, 1, 28, 28]
```

For color images:

Wrong:

```text
[8, 64, 64, 3]
```

Correct:

```text
[8, 3, 64, 64]
```

<br>

## Bug 4: Flattening Too Early

Wrong before convolution:

```text
[4, 784]
```

Correct before convolution:

```text
[4, 1, 28, 28]
```

Flattening is usually done later, after convolution and pooling, before a final fully connected classifier.

# 13. 🔗 Connection to Week 10 Tensor Operations

Day 2 uses several ideas from Week 10:

| Week 10 Skill | CNN Shape Use |
|---|---|
| `shape` | inspect image tensor dimensions |
| `reshape()` | flatten image tensors when needed |
| `unsqueeze()` | add missing batch or channel dimensions |
| indexing | inspect one image or one channel |
| batch dimension | process multiple images together |

The key difference is that CNNs usually keep the image as:

```text
[N, C, H, W]
```

instead of immediately reshaping it to:

```text
[N, features]
```

# 14. 💻 Full Practice Code

```python
import torch
import torch.nn as nn

# --------------------------------------------------
# 1. Grayscale image batch
# --------------------------------------------------

gray_images = torch.randn(4, 1, 28, 28)
print("Gray image batch shape:", gray_images.shape)

# --------------------------------------------------
# 2. Color image batch
# --------------------------------------------------

color_images = torch.randn(8, 3, 64, 64)
print("Color image batch shape:", color_images.shape)

# --------------------------------------------------
# 3. Flatten grayscale images for a fully connected layer
# --------------------------------------------------

flattened = gray_images.reshape(4, -1)
print("Flattened gray image shape:", flattened.shape)

# --------------------------------------------------
# 4. Add missing batch dimension
# --------------------------------------------------

single_image_with_channel = torch.randn(1, 28, 28)
print("Before batch unsqueeze:", single_image_with_channel.shape)

single_image_batch = single_image_with_channel.unsqueeze(0)
print("After batch unsqueeze:", single_image_batch.shape)

# --------------------------------------------------
# 5. Add missing channel and batch dimensions
# --------------------------------------------------

single_image_no_channel = torch.randn(28, 28)
print("Before channel/batch unsqueeze:", single_image_no_channel.shape)

single_image_ready = single_image_no_channel.unsqueeze(0).unsqueeze(0)
print("After channel/batch unsqueeze:", single_image_ready.shape)

# --------------------------------------------------
# 6. First Conv2d shape check
# --------------------------------------------------

conv = nn.Conv2d(
    in_channels=1,
    out_channels=8,
    kernel_size=3
)

conv_output = conv(gray_images)
print("Conv output shape:", conv_output.shape)
```
